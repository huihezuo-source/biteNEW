# biteNEW

让 AI 学会做无旁白的股票知识短片：3:4 竖屏，约 160 秒，观众读字幕，画面是 GPU 渲染的真 3D。

这里有四个技能和一个渲染引擎，覆盖选题、写稿、排场面、配乐、出片和审片。质量线按《分母》《倒影》两条片子定，没过独立审片不交付。

## 四个技能

| 技能 | 管什么 | 里面有什么 |
|---|---|---|
| `stock-film-copy` | 选题和文案 | 抖音 310 条股票视频的数据、选题打分、开场写法、审稿提示词 |
| `bitxinyu-film-craft` | 把文案排成场面表 | 比特新语 23 条片子的逐镜反推（不含文案全文）、138 张技巧卡、192 个动效叫法 |
| `film-bgm` | 配乐 | 量参考曲、写新曲简报、查有没有撞曲 |
| `gpu-knowledge-film` | 渲染和审片 | three.js + GLSL 引擎、155 个转场、5 个打击特效、量化尺子、示例工程 |

做一条片子就按这四行的顺序走。

## 安装

把下面这段发给你的 AI：

> 克隆 https://github.com/huihezuo-source/biteNEW ，运行里面的 install.sh，补齐缺的依赖，再按 README 的“验证”一节渲一张图给我看。

也可以自己装：

```bash
git clone https://github.com/huihezuo-source/biteNEW.git
cd biteNEW
bash install.sh
```

`install.sh` 做这几件事：

1. 把四个技能链接到 `~/.claude/skills/`。技能是链接过去的，仓库要留在原地。
2. 下载两个中文字体，共 43 MB，太大没放进仓库。
3. 检查依赖。缺什么它会打印安装命令，不会替你装。

| 依赖 | 用途 |
|---|---|
| ffmpeg | 出视频 |
| Python 3：playwright、numpy、scipy、pillow、librosa | 渲染、拼图、音频、量化 |
| Playwright 的 Chromium | 跑 WebGL |

不用 Claude Code 也可以。这些技能就是 Markdown 加脚本，把 `skills/` 放到你的工具读技能的地方，或者让它直接读 `SKILL.md`。

## 验证

用《第二天》的工程渲一帧：

```bash
T=$(mktemp -d)
cp -r skills/gpu-knowledge-film/engine/. "$T"
cp -r skills/gpu-knowledge-film/examples/第二天/src/. "$T/src"
cd "$T"
./go.sh 120 stills 60.3 --w 540 --h 720 --q mid --prefix t
ls out
```

`out/` 里出现一张红屏手机的图，就说明引擎能跑。

## 用法

直接说就行：

- “做一条股票视频，选题你定”
- “这个题有没有流量：……”
- “这段文案怎么拍”
- “这首歌很好，想做一首类似的配乐”

AI 会从 `engine/` 拷一份工程，写字幕和镜头，先出样片，再出全片。每条片子要单独设计世界，`examples/` 只用来学写法，别照抄。

| 步骤 | M1 Max 上的耗时 |
|---|---|
| 720×960 草稿，161 秒 | 约 7.5 分钟 |
| 1440×1920 成片 | 约 30 分钟 |

## 运行环境

在 Mac（M1 Max，ANGLE Metal）上实测过。Windows 和 Linux 没测过：`render.py` 会按系统换图形后端，能不能跑、速度多少要自己试。显卡弱的机器会慢很多。

## 没放进来的东西

- 比特新语的原片、字幕和配乐。反推文件里的文案全文和分镜字幕都删了，要看请去 B 站。
- 配乐文件。示例工程不带音频，做片子要自己准备音乐。
- 流体、真海面这些没接进引擎的开源项目。地址在 `THIRD_PARTY_NOTICES.md`，要用时再下载。155 个转场已经内置。
- 发布复盘和配乐记录。这两个文件换成了空模板，填你自己的。

## 发布前看三件事

1. **账号资质。** 《抖音社区财经行业公约（试行）》（2025-12-16）限制未经资质认证的账号发财经专业内容，详情看 `stock-film-copy` 第 0 步。片子不荐股，不给买卖建议，虚构的部分写进声明。
2. **配乐版权。** 别人的曲子换一种乐器，用的还是那条旋律。用之前先看 `film-bgm` 开头的判断，这只是工作判断，不是法律意见。
3. **数字。** 片子里的数字要能溯源。示例工程的 `data.js` 是做片时取的，新片子要自己取、自己核。
