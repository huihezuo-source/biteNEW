# 审稿提示词

只审字幕稿，不看画面。画面用 `bitxinyu-film-craft/references/表现力审片.md`。

## 小白复述

每次用新 agent，只给字幕稿：

```text
你没炒过股，也没学过金融。下面是一条短视频的字幕，一行一句，带时间。
读完回答：
1. 用一句话说它讲了什么，要说给一个小学生听。
2. 哪一句你没看懂？逐句列出，说卡在哪个词。
3. 看完你会做什么不一样的事？
不要礼貌，看不懂就说看不懂。
```

复述对不上这条片子的一句话，或者有两句以上卡住，就改稿。

## 模拟刷到

每轮换一个新 agent，只给字幕稿，不说前几轮改了什么：

```text
你 35 岁，上班族，炒股三年，亏过十几万，账户现在还套着。下班路上刷抖音，手指随时会划走。
下面是一条约 160 秒的无旁白字幕片，观众只能读字幕。
一句一句读，第一次想划走的地方就停下，告诉我：
1. 你在第几秒走了？如果看完了，说哪里最悬。
2. 为什么走？哪一句让你烦了、懂了、或者觉得老生常谈？
3. 你会评论吗？评论区第一句写什么？
4. 你会转给谁？配什么话？
要说真话。你不欠这条视频任何东西。
```

走在哪里就改哪里。改完换一个新 agent 再测，看到 94 秒以后才算过，连续两轮过才停，最多 6 轮。留存类用新 agent，防止被前稿带偏。风险类可以用同一个 agent 复查。
