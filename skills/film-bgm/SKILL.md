# 片子配乐

用户的想法：别人的音乐不错但没版权，就用 AI 做一个类似的。这条路能走，关键在“类似”到什么程度。

## 先说清版权

**只换乐器不算绕开版权。** 钢琴换吉他，旋律还是那条旋律，用的还是原曲。翻唱翻奏要取得词曲权利人的许可。《著作权法》第十三条写明，改编已有作品产生的新作品，行使著作权时不得侵犯原作品的著作权。只改配器算不算侵犯“改编权”，实务里有不同看法，但不管归到哪项权利，没授权就有风险。

| 可以学 | 不能用 |
|---|---|
| 速度、调式、节拍感 | 旋律，包括换调、变速、换乐器后的旋律 |
| 配器气质、音色的明暗 | 能听出来的动机和 hook |
| 情绪起伏、段落结构 | 歌词 |
| 爆点的位置和力度 | 原录音，切一小段也不行 |

所以做法是**学感觉，重写旋律**。不要把原曲上传给 AI 做翻奏或风格迁移，提示词里不写曲名和歌手。

这段是工作判断，不是法律意见。要投广告或商用，先找律师或买授权。

**用之前查清：** 从别人的视频和素材里取的曲子，版权状态要先查过。发布时优先从平台自己的音乐库选同一首，或者换成原创。

## 流程

### 1. 量参考曲

```bash
python3 scripts/music_tools.py brief 参考曲.wav --out brief.md
```

得到时长、速度、调、16 段能量曲线、重音时间、段落边界。这些都是可以学的东西。例子见 `references/例子_千年之后量出来的数.md`。

### 2. 写新曲简报

用自己的话描述气质，换一种主奏乐器，段落表按片子的结构点写：

```text
Instrumental, no vocals. {时长} seconds, {BPM} BPM, {调}.
Mood: {两三个词，比如 restrained, cinematic, slowly rising tension}.
Lead: {新的主奏乐器}. Support: {两三种配器}.
Original melody, simple and memorable.
Structure:
0:00-0:17 sparse, {乐器} alone, room to breathe.
0:17 big hit: drums and low strings enter at once.
0:17-1:19 steady groove, gradually fuller.
1:19-1:33 drop to almost nothing, one quiet line.
1:33 second big hit, the fullest moment of the track.
1:33-2:39 full, then thinning out.
2:39-2:43 long decay to silence.
```

时间点换成这条片子的结构点。音乐生成器未必能卡准秒数，所以第 5 步要查。

### 3. 选生成方式

| 方式 | 适合 | 要注意 |
|---|---|---|
| 抖音 App 里的 AI 音乐创作 | 只发抖音 | 无旁白股票片常用。用户在 App 里操作，别的平台能不能用看条款 |
| 在线 AI 音乐（Suno、Udio、ElevenLabs 等） | 质量高、出得快 | 用户自己登录。商用权和套餐有关，用之前读当前条款 |
| YuE2 Studio（本地，家里 4090） | 想改谱、改节奏 | 工作室 MIT，模型权重是 CC BY-NC 4.0 加个人创作者条款，商用先读清楚。不要用它的翻唱和旋律提取处理别人的歌 |
| minimax-h3-studio（ComfyUI） | 想走本地流程 | 带音乐功能，作者只在 Ubuntu 加 4090 上测过 |
| 免费曲库（Pixabay Music、Openverse） | 省事 | 每首看授权，留下授权页截图 |
| 代码写（Tone.js 加采样钢琴） | 完全自有 | Salamander 钢琴采样要署名。质量比不上生成模型，适合极简氛围 |

音效：`audio_synth.py` 代码合成、earshot（201 种，MIT）、freesound（每条看授权）、mixkit 转场音效、ElevenLabs 文字生成音效。

### 4. 查有没有撞

```bash
python3 scripts/music_tools.py check 参考曲.wav 新曲.wav --hits 17.07,93.87
```

相似度用翻奏检测的办法算，换调、变速、换音色都认得出来。2026-11-02 校准：

| 对比 | 分数 |
|---|---|
| 同一首 | 0.96 |
| 《千年之后》变调变速压暗音色 | 0.55 |
| 同一首曲子的其它版本（光遗传学、镜像分子、学鸟的配乐） | 0.40–0.48 |
| 不相干的曲子（中微子、脑内擂台） | 0.07–0.10 |

低于 0.20 算没撞，0.20–0.35 人耳细听，高于 0.35 换一版。这个分数看整首，查不出四小节以内的撞车，生成后还要人听一遍。AI 生成的曲子也可能撞别的歌，这个脚本只能比你给它的参考曲。

### 5. 对上片子的结构点

`check` 会报每个重音和片子要求差多少。差 0.3 秒以内，在画面上挪。差得多就换一版，或者在小节线上剪：`gpu-knowledge-film/examples/满仓/make_music.py` 有按小节回跳延长的做法。

重音要实测。《千年之后》节拍表按底鼓拟合写的 17.49、94.0 就偏晚，实际在 17.07、93.87。

### 6. 留记录

每首写进 `references/配乐记录.md`：工具、账号套餐、日期、提示词、是否参考了别的曲子、相似度分数。发布后被投诉时，这份记录最有用。
