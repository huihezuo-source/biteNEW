排场面表时先查这里，有现成的就别自己写。来源是一批开源项目（2026-11-02 整理）。接进引擎的随技能分发，其余项目的下载地址在仓库根目录的 `THIRD_PARTY_NOTICES.md`，下载到 `<特效库目录>/`。

预览：`references/转场总览.jpg`（全部 154 个转场的中间帧）。

## 一、已经接进引擎，直接用

### 转场：155 个

来自 gl-transitions（MIT，个别 BSD）。`engine/src/fx.js` 负责调用，转场时两个镜头同时渲染，所以运动模糊、景深、Bloom 都还在。`LissajousTiles` 编译不过，不用。

在 `film.js` 里加一行：

```js
import { timeline } from './fx.js';
// 返回的对象里加：
transitionAt: timeline([
  { at: 17.07, dur: .9, name: 'Overexposure', ease: E.io2 },
  { at: 42.0, dur: 1.2, name: 'InkBleed', params: { /* 覆盖默认参数 */ } },
], t => shotAtTime(t)),
```

`at` 是切点，`dur` 是总时长，切点前后各一半。转场期间每帧要渲染两遍，mid 档 720×960 仍有约 12 fps。

| 想要的效果 | 用哪个 | 对应的技巧 |
|---|---|---|
| 推到爆白换世界 | Overexposure | 推到爆白换世界（酿酒） |
| 胶片漏光 | FilmBurn | |
| 边缘金光烧穿 | BurnThrough、UndulatingBurnOut | 账户烧穿、K 线烧掉 |
| 墨在纸上化开 | InkBleed | 一个进度条演一辈子（时间倒流） |
| 一滴水砸下 | WaterDrop、Ripple | 一滴水定住循环（脑内擂台） |
| 径向冲进去 | CrossZoom、DreamyZoom | |
| 甩镜头 | WhipPan、WhipSpin、WhipTilt | 快节奏连接 |
| 钻进隧道 | Tunnel | 掉进瞳孔（光遗传学） |
| 崩解成沙、风吹散 | Disintegrate、Wind | 错过的东西碎掉（37 法则） |
| 碎裂 | Shatter | 三拳打裂屏幕（脑内擂台），时长给足，中段才碎 |
| 撕开 | PaperTear | 一根线就是刀（剃刀） |
| 花屏、掉信号 | StripDatamoshGlitch、GlitchDisplace、TvLostSignal | 系统崩了、爆仓 |

**用的时候记住：** 转场是场面的一部分。字幕说烧，才用烧穿；字幕说碎，才用碎裂。同一种转场全片只用一次。比特新语一条片子切镜中位数才 12 次，大部分换场靠世界里的东西，这些转场留给最重要的几处。

### 打击特效：5 个

在镜头的 `update` 里写，Bloom 之前作用在 HDR 上：

```js
pp.fx = pp.fx || [];
pp.fx.push({ fx: 'shock', k: 半径, c: [.5, .55], w: .13, amp: .05, split: .02, col: [.9, .7, .4] });
```

| fx | 效果 | 参数 | 对应 |
|---|---|---|---|
| `shock` | 冲击波，三通道半径错开就是彩虹环 | k 半径 0–1.6，w 宽度，amp 强度，split 色散 | 彩虹冲击环（脑内擂台） |
| `rays` | 体积光，从亮处往外拖光柱 | k 强度，c 光源位置，decay，thr 亮度阈值 | 舞台光、日出 |
| `glitch` | 随机块错位加通道分离 | k 强度 | 一闪而过的系统故障 |
| `ink` | 一帧墨纸，亮处变墨、暗处变纸 | k 0 或 1，thr | 一帧墨纸（脑内擂台） |
| `lens` | 桶形畸变加边缘色散 | k 强度，c 中心 | 重击时画面一鼓 |

引擎原有的 `pp.flash`、`pp.warp`（径向模糊）、`pp.ca`（色差）、`pp.shakeX/Y`、`pp.streak` 继续用。

## 二、已下载，要用时再接

| WebGL-Fluid-Simulation | 烟、墨、流体，跟随运动 | MIT | 把时间步固定成 1/帧率，保证逐帧确定。适合“一张流体用到底” |

- 这些技能不在本仓库，没装就跳过：`hyperframes-animation` 有转场目录和动效规则，`video-shotcraft` 有 157 张镜头配方卡，`huashu-art-motion` 有 35 种艺术风格。

- yihui-dev/awesome-opus5-5-videos：700 多条代码视频和提示词。guanmo-ai/awesome-ai-motion：提示词整理。Vincentwei1021/mg-styles-15：15 种 MG 风格的提示词和源码。这些没下载，要找灵感时打开看。

## 四、不用的

- **LYGIA**：Prosperity 协议，只许非商业免费使用。我们的账号要变现，不用。
- **ShaderGradient、tsParticles、Theatre.js、Hydra、Rough.js、GSAP**：要么我们有更好的，要么和逐帧渲染的管线不合。
- **pixelfx**：像素风，和片子气质不合。做像素风片子时可以用。
