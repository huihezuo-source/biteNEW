# 技巧卡全集

每张卡：什么时候用 → 画面怎么做 → 实现要点 → 改 3:4 注意什么。按片子排列，按情况查请看 `文案到画面.md`。

## 01 银牌的眼泪

- 【一滴泪砸出片名】文案里有一个最小的具体物件时用 → 片名前 1.5 秒推到主角，让这个小东西掉下去，落地接闪白和涟漪 → 落地帧对准 17.03 秒重音，下落用重力曲线，闪白放色调映射之后 → 主角放竖屏中线，片名改两行，涟漪宽度压到八成屏。
- 【先盖答案再揭开】要证明一个反直觉结论时用 → 用黑块盖住名次、小人改灰，观众和被试一样不知道谁是谁，分数出来再一把揭开 → 黑块硬切上屏，揭开时全场亮一档 → 刻度线放下三分之一，上面留给主体。
- 【一把尺子量两头】两件事差距一样、意义相反时用 → 两个括号写同一个数，一个金字一个红字 → 先推近分开讲，再拉远同屏 → 横跑道改竖跑道，终点线放顶上，括号放侧边。
- 【灯按心情给】地位和心情相反时用 → 站得高的人灯最暗 → 光锥用叠加混合的半透明梯形，透明度金 .35、铜 .22、银 .12 → 光锥拉长，顶上留两成黑。
- 【另一个你跑在前面】抽象的“另一种可能”要看得见时用 → 把主角复制一份，改金色半透明，放在前面，动作完全同步 → 同一条动作曲线偏移时间，透明度 .6，模糊 6 像素 → 上下错开，金人在上。
- 【第一帧只加一个虚线框】结尾要回扣开头时用 → 回到第一帧，别的都不动，只多一个虚线框和一个虚影 → 第一帧的相机和灯光参数存成常量，结尾直接复用 → 第一帧构图要给后加的东西预留空位。

## 02 光遗传学

- 【掉进瞳孔】开场要让观众变成当事人时用 → 第一帧放一只大眼睛，瞳孔放大把全屏吃黑，黑里出现他看到的东西 → 极坐标 fbm 画虹膜，瞳孔半径和镜头推同时动 → 竖屏把眼睛放在中线偏上，高度占屏六成，宽度别超屏。
- 【粒子聚成下一个主角】两段内容要无缝接上时用 → 上一段的粒子全部飞向一点，这一点就是下一段主角身上的东西 → 粒子位置在两套目标之间插值，用 `smoothstep` 分批出发 → 聚合点放在屏幕上三分之一，留出下面的字幕位。
- 【零件跨场景不动】一个东西从 A 世界搬到 B 世界时用 → 背景溶解换场，只有这个零件留在原来的屏幕位置，再飘向新目标 → 零件单独一层，不参加溶解 → 零件留在屏幕中线，竖屏左右空间不够横移。
- 【一个细胞点亮全网】要表现一点小事传遍全局时用 → 细光碰一个节点，亮光沿枝条跑，再传给邻居，同时出片名 → 枝条存路径长度，用高斯波前扫过，邻居按距离延迟 → 神经网改成上下长，光从顶部打下来，片名放中间。
- 【整盘朝光游】讲群体行为时用 → 几千个点先乱游，一个信号出现，全部涌过去 → 位置存纹理，`GPUComputationRenderer` 更新，皿壁滑动 → 圆皿放在屏幕上半，放大镜放下半。
- 【他的世界只用颗粒】要演受限的感官时用 → 当事人看到的东西全用琥珀粒子画，再退成马赛克 → 粒子撒在形状内部，后段按格子吸附 → 手和本子改成上下排列，地平线放上三分之一。

## 03 剃刀

- 【一根线就是刀】文案要表达“删掉、取舍”时用 → 一根白线打穿屏幕，线一边的东西全部掉光 → 物体按到线的有向距离分两半，一半下落淡出 → 竖屏切线改成横线，从上往下切，留下的放上半。
- 【线转成下一个零件】两段内容要接上时用 → 刀不消失，转 90 度变成下一张卡的分隔线 → 线的角度和长度做动画，终点和下一张卡的线重合 → 3:4 宽度小，线转完长度控制在屏宽五成以内。
- 【想法长成树，越远越红】要演脑子乱想时用 → 从一条消息长出枝条，每层更红更细，亮字和灰字混排 → 递归样条，颜色按层插值，文字绑节点 → 竖屏让树往下长或往上长，气泡放在底部。
- 【一笔画出荒唐的东西】要说“这套方法什么都能解释”时用 → 让严肃的机器画出一头大象 → 傅里叶级数取前几项，圆串画线 → 大象占屏宽七成，机器放在上方收缩成笔。
- 【纵轴一压露馅】要揭穿一条看起来很准的线时用 → 新数据落下，坐标比例变，曲线冲出屏幕 → 顶点乘 `uScaleY`，0.8 秒缓动 → 竖屏高度大，压缩倍数可以更狠，冲出顶部更远。
- 【角落时钟替你数时间】等待和焦虑要量化时用 → 角上放一个真在走的时钟，几秒跑完三小时，结尾跳到 07:12 → 时钟绑全局时间轴，分段映射 → 放左上，字号不小于屏宽 6%，别被平台水印盖住。

## 04 刷分的捷径

- 【角上的分数永远在涨】全片讲同一个规律、案例很多时用 → 每段换场景，角上的数字一直在跳，每段换一个单位（0.00、0 次、100%、1c/条）→ HUD 单独一层，不跟场景走，分数按拍子跳 → 放右上，别放左上，平台水印会挡住。
- 【换机位抓现行】要揭穿一个假象时用 → 先用正面机位演得天衣无缝，再硬切侧面，画中画留着旧机位 → 同一场景两台相机，画中画走渲染到纹理 → 竖屏画中画放顶部中间，占屏宽四成。
- 【一个字打散成分数】要说“它只认数字”时用 → 大字由几千个点拼成，炸开，重组成 0000 → 文字采样成点，两组目标位置插值，中间加噪声 → 竖屏字高不超过屏宽九成。
- 【时钟狂奔当笑点】“再也没有”这类话要量化时用 → 暂停后旁边时钟飞跑，几秒跑过 8 年 → 时间按指数加速映射 → 时钟放方块下面，竖屏空间足够。
- 【规则一条条变成墙】要演“越管越漏”时用 → 每写一条规则落一堵红墙，光点绕开，墙多到成迷宫，绿线还能钻过去 → 迷宫预生成，绿线用预计算路径，按规则数放墙 → 手册放上面，场地放下面。
- 【分数变横杠】结尾要说“没人看的时候”时用 → 全片常驻的数字突然消失，只留一道横杠，同时开一盏暖灯 → HUD 绑状态，灯用 `ease` 拉起 → 横杠和“没有人打分”放大一号，手机上要看得见。

## 05 中微子

- 【数字替你读秒】开场要让人感到“此刻正在发生” → 左上放一个连续累加的大计数器，每秒加 650 亿 → 值等于 `650e8*t`，每帧重写，用等宽数字防抖 → 3:4 放主体上方，位数多时字高不超过屏宽的 1/12。
- 【一镜拉到地球】要交代“无处不在” → 指纹、手、星球连续缩小，中途不切 → 对数缩放，雨丝留在屏幕空间当参照 → 3:4 上下空间多，手从底部出画，地球压在上三分之二。
- 【三个信使比赛】要证明“只有 X 做得到” → 同一张图上先后跑三条线：红的带偏，金的半路灭，青的直达 → 同一机位不切，标注长在线上（来路不明、熄灭） → 3:4 宽度不够，改成上下排布，源在顶，地球在底。
- 【下潜报深度】要让人觉得“深” → 穿过冰面后只留深度尺和跳数，2.2 秒到 1450 m → 速度前快后慢，气泡反向掠过 → 3:4 天然合适，尺子贴左，字幕留底。
- 【年份连跳加闪】要压缩十几年 → 金色年份大字 8 秒跳完 18 年，最后 4 跳每 0.7 秒一闪，新井炸成光团 → 闪的强度逐次加大 → 3:4 年份放上方，点阵放下方。
- 【科学图的颜色留到结尾】片子前面讲硬知识，结尾转到人 → 把数据配色用到“你”的物件上，全片只给三次 → 共用一张 1D LUT，让观众先学会颜色的意思 → 3:4 指纹居中，占屏宽约 80%。

## 06 我爱你一千遍

- 【给一句话装读数】要量化一个抽象的东西 → 句子正下方放等宽大读数，跟着次数滚动 → 读数按公式真算，归零那一帧配闪白和音效 → 3:4 气泡放上三分之一，读数在中间，字幕留底。
- 【每个字下面一根柱】要证明两句话不一样 → 逐字排开，每字下一根柱，两句同屏用同一把尺子 → 柱向下长，长柱红光，短柱灰 → 3:4 一行放不下 15 字，改成两行，每行 8 字以内。
- 【一年铺成 365 格】要说日子重复 → 27 列 × 14 行格子，5 格白彗星越扫越快，格子变灰 → 速度从 40 天/秒加到 90 天/秒，读数同步掉到 0 → 3:4 改成 14 列 × 27 行，从上往下填。
- 【最后一格吃掉全屏】要转折 → 全静止后只变一格的颜色，3 秒推到铺满，闪白 → 用指数推近，缩放中心对准那一格 → 3:4 格子竖向够长，红格放下三分之一，推的路更长。
- 【规则破了才给颜色】全片要有一次情绪爆发 → 前面严守单色，转折时一次给全彩，用完收回 → 全彩段只放 25 秒，线细且暗，字幕压得住 → 3:4 流场从底部喷向上方，字幕放中部。
- 【结尾留一根光标】要把行动交给观众 → 全黑，红色光标闪 5 秒，一行小字 → 光标和前面输入框是同一个物件 → 3:4 放屏幕正中，别放底部，抖音底部会被按钮盖住。

## 07 以牙还牙

- 【每格都是真数据】要让观众信结论 → 把几万次模拟直接铺成墙，再拉远 → 数据写进 DataTexture，最近邻采样，不开 mipmap → 3:4 把墙转 90°，120 列 × 200 行，回合从上往下走。
- 【四句四小节】开场要连续打脸 → 四句短话各 2.125 秒，同一面墙硬切换颜色比例 → 切点卡 n×2.125 秒，每切配亮度小闪 → 3:4 字改两行，字高不超过屏高 8%。
- 【两行条带演一辈子】文案讲两个人互相反应 → 两行格子并排长，错开一格，红金就交替了 → 真跑两个策略，加一次随机误判 → 3:4 条带竖放，从上往下长。
- 【一圈波打回自己】要说“会报应到你身上” → 中心一格是你，波出去，从四角收回，打中你 → 全部按到中心的距离算，不动相机 → 3:4 外圈到达上下边更晚，把回收时间按屏幕长边算。
- 【把未来铺成地砖】要讲“以后” → 把两行条带平放到地上，伸向地平线，朝镜头滚 → 透视平面，砖发光，地平线加光晕 → 3:4 地平线放上四分之一，路更长。
- 【字跟着图走】一屏里图和字抢位置 → 字幕不固定，图在下字就在上 → 每镜单独定字位，保持宋体和模糊显影不变 → 3:4 优先放上方，底部 15% 留给平台按钮。

## 08 不会起风

- 【风要看得见】要讲看不见的东西 → 用白色短线画流动，再配一个小物件报方向 → 短线沿路径取 UV 流动，小物件和流向绑同一个变量 → 3:4 环流改成上下两层，别横贯全屏。
- 【一天压到 22 秒】要讲循环 → 机位锁死，只动天色、太阳、时钟、温度计 → 所有动画挂一个时间变量 `hour`，天色用 LUT → 3:4 剖面上下切，天占上三分之二，地下放温度计。
- 【竖线转横线】要讲“被什么力改变了” → 地球上的风线从经向连续变成纬向，不切 → `v=normalize(mix(vMeridian,vZonal,u))`，粒子在球面积分，`u` 跟字幕走 → 3:4 地球占屏宽 90%，放上半屏。
- 【小事件越来越密】大转折前有一段安静 → 远处闪电 7 次，间隔从 3.7 秒缩到 1.1 秒，接闪白 → 倒着从落点排时间 → 3:4 闪电放在主体上方的空天。
- 【两条线一个距离表】要讲分开和重逢 → 地球上两条光线分头飞，角落一个距离数字涨到 7,219 再落到 0 km → 线头沿大圆插值，距离真算 → 3:4 距离数字放地球下方，字高不小于 4%。
- 【小物件贯穿全片】结尾要回收主题 → 片子前段让观众学会读一个小物件，结尾只用它说结论 → 全片只有它是红色 → 3:4 人物占下半屏，围巾留出左右飘的宽度。

## 09 熵增

- 【一个进度条走完一间屋】文案说放着不管会怎样时用 → 3 秒里窗变暗、花垂头、灰堆满、相框歪、蛛网长，全部同时发生 → 所有动画吃同一个 decay（0 到 1），各自用 smoothstep 错开 0.1 → 改 3:4 时房间收窄，窗和桌竖着排，字幕放在地板上
- 【同一批物件倒放一次】文案先讲坏、后讲修时用 → 房间、城市、两颗光、粒子前半段坏一次，后半段按原构图修回来 → 场景写成 scene(decay)，修的时候 decay 从 1 走回 0 → 改 3:4 时两次构图不能变，观众要认得出
- 【字也变成乱的样子】文案说回到最大概率的样子时用 → 气泡框退掉，字按原字号漂散 → 字符面片加噪声位移，不转不缩 → 改 3:4 时聊天区占屏宽 80%，上下多留 30% 给字漂
- 【把数真算出来打满一行】文案说多到数不清时用 → 正中一行 30 位真实数字，先滚后定 → 用大数算 C(100,50) 逐位显示 → 改 3:4 时拆成 3 行，每行 10 位，字号不小于屏宽 5%
- 【光条扫地数字归一】文案说出力把乱压回去时用 → 光条推走粒子，身后露出整齐的格子，计数掉到 1 → 粒子用 uSweep 判定，计数用指数插值 → 改 3:4 时光条从下往上推，路程更长
- 【没写完的片名】结尾想让观众自己接话时用 → 「不清扫，就会」后面 3 个小点隔 1 秒补一个 → 点用片中的冰蓝色，暗示后面是什么 → 改 3:4 时分两行，点放第二行末尾

## 10 余波

- 【话当石头砸进网里】文案说一句话伤人时用 → 气泡从上方掉下，砸到网上起环波 → 气泡 y 用重力加回弹，落点写进波源数组 → 改 3:4 时网的视角抬高，气泡落在屏高 45%
- 【字骑在波上走】文案列举后果一件件扩散时用 → 每个标签绑在一道环波上，跟着往外走、变淡 → 标签位置等于波源加方向乘 c(t−t₀)，alpha 随半径衰减 → 改 3:4 时标签走上下方向，横向不够宽
- 【卡尺在跳，人没动】文案说距离变了但没人动时用 → 平视网格横压竖拉，两点下方卡尺跳数，头顶标 Δv = 0 → x 乘 1+a·sinωt，y 乘 1−a·sinωt，a 随时间放大 → 改 3:4 时两点上下摆，卡尺竖放
- 【平息圈】文案说被抚平时用 → 从一个人起一个圆，圆内高度归零，圆边扫到另一个人 → h 乘 smoothstep(R−w, R+w, d) → 改 3:4 时圆从屏幕下方推到上方
- 【同一个动作演两遍】科学事件要对上人事时用 → 0:00 黑洞互绕相撞，1:04 两个人互绕相撞，同样的加速和闪 → 共用 orbit(t) 函数，只换外观和标签 → 改 3:4 时绕转半径限制在屏宽 30% 以内
- 【闪完贴近网面】要换尺度时用 → 闪白遮住切换，相机贴到网面，峰线横贯全屏 → 相机高度压到网宽 8%，远端用雾 → 改 3:4 时地平线提到屏高 75%，下方多放网

## 11 37法则

- 【竖光切开答案】开场要把结论当悬念放出来时用 → 竖光 0.4 秒扫进来，空心大字被切开，左实右空 → 光停的位置等于答案本身，用 step 切两张贴图 → 改 3:4 时字改两行，光改横光，切在屏高 36.85%
- 【错过的东西碎掉】文案说不能回头时用 → 左边竖条碎成灰屑往下掉，只留眼下这一根 → 每根条拆成小矩形，加重力，从左到右错开 → 改 3:4 时碎屑多落一段，屏高够长
- 【一颗光头把云画成线】要说结果是算出来的时用 → 先灰点云，计数越大越贴线，再一颗光头沿曲线跑，身后变金线 → 点的散布按 1/√N 收紧，线用 drawRange 逐段显示 → 改 3:4 时图占屏宽 86%，曲线高度拉到屏高 40%，计数放图上方
- 【一百次人生摊成格子】要把概率换成次数时用 → 10×10 小卡片随机揭开金或红，计数跑到 37 : 63 → 打乱下标，保证最后比例正好 → 改 3:4 时格子改正方形，上下放字
- 【整张图卷成一点再炸开】要换思路时用 → 图转约 20° 缩成一点，黑一下，白圈炸开 → 组做 rotate 加 scale，easeInCubic，炸开压在小节线上 → 改 3:4 时转角减到 12°
- 【一根线变成下划线】收尾要把话交给片名时用 → 贯穿全屏的金线收缩成片名下面一小段 → 只动 scaleX → 改 3:4 时线上下留足两句字的空间

## 12 上头

- 【心跳数跟着剧情走】文案讲等待和情绪时用 → 全屏一条心电线加右上 BPM，消息到达时 R 波翻倍，BPM 跳 → 每拍幅度写进数组，事件改写当前拍 → 改 3:4 时线放屏高 30%，聊天框放下面，上下分开，少一次遮挡
- 【时钟快进】文案说等了很久时用 → 对话框里一个大钟 8 秒走 4 小时，分钟越跳越大 → 用非线性时间表直接写几个关键值 → 改 3:4 时钟放聊天框上方，字高可以到屏高 8%
- 【后面的数字别停】大字盖住图表时用 → 图压到 20%，计数在字后面继续跳 → 计数层不受压暗影响，只降透明度 → 改 3:4 时计数放字下方，别被字挡住
- 【拉杆接下拉】要把两个比喻接起来时用 → 老虎机拉杆往下，叠化成手指下拉刷新 → 两个动作同方向、同时长，叠化放在动作中间 → 改 3:4 时手机本来就是竖的，比横屏更合适
- 【预测准了，尖峰就平】文案说习惯了没感觉时用 → 同样的消息，起伏一次比一次小，最后是直线 → 幅度乘 exp(−n/τ)，n 是出现次数 → 改 3:4 时两条线上下排，各占屏高 30%

## 13 酿酒

- 【一张流体用到底】文案讲「形式一直变，有样东西没变」时用 → 同一张酒液先占满屏，再装进 8 个容器，再调暗铺在金句底下，最后进两只杯子 → 流体写成一个函数，容器用模板缓冲裁，亮度和阈值走 uniform → 3:4 下容器改瘦高，时间轴从顶部横条改成右侧竖条，8 格横排在 1440 宽里字太小
- 【推到爆白换世界】文案从宏观跳到微观时用 → 推近一个发光物到过曝，在白场里换场景 → 缩放中心锁物体，曝光到 8 倍，换场帧压底鼓 → 3:4 下发光物放在屏高 55% 处，推近时别盖住底部字幕区
- 【片名压在液面上】片名要一下亮出世界时用 → 上黑下金，一条泡沫线分屏，字贴在线上 → 液面函数加泡沫噪声 → 3:4 下液面放在屏高 60%，上方黑区更大，片名可放到屏宽 60%
- 【滚筒印出浮雕】讲古代实物证据时用 → 一根竖条纹圆柱滚过，身后留下画面 → 画面是高度图，遮罩 `x < cylinderX`，圆柱只是一张横向渐变 → 3:4 宽度不够，改成从上往下滚，图改竖构图
- 【守卫环断开才连线】讲「一松就通」的机制时用 → 两个光点各被虚线环围住，环断开，光晕融合，一根金线连起来 → 虚线走 dashOffset，断开时每段往外推 → 3:4 下两点改上下摆，线竖着连
- 【祝酒词漂过光斑】一个词有很多说法时用 → 约 20 种语言的词漂过散景，字号 3 档，一个放大变金 → 文字层匀速漂，重点词单独缩放 → 3:4 改成从下往上漂

## 14 学鸟

- 【背景层就是答案】文案最后要点破「一直都在的东西」时用 → 从第一帧起铺一层像装饰的线，前面不提，临近结尾才说它就是答案 → 流线写成流函数等值线，点破时亮度和线宽走 uniform 提上去 → 3:4 下线要横穿屏中段，条数从 15 加到约 22，避开底部字幕区
- 【线的颜色判对错】要让观众自己看出谁对谁错时用 → 成功者身边线变金下压，失败者身边线发红撕裂 → 流函数加噪声项，`stall` 越大越乱越红 → 3:4 下两个对象上下放，比左右放更宽松
- 【分屏一句一半】开场要一个悖论时用 → 竖线分两半，两句字幕各压一半，一边动一边定，背景线连续穿过 → 两套背景按 x 混合，线只算一遍 → 3:4 改成横线上下分屏，字幕放各自半屏下沿
- 【秒表按真实时间走】一个数字本身很小（12 秒、5 分钟）时用 → 镜头不动，让事情真的发生这么久，角上秒表同步走 → 计时器等于 t − t0，不加速 → 3:4 屏宽短，12 秒横穿太慢，改斜向飞或跟拍
- 【替换测试表】要把抽象分层变成能用的工具时用 → 一个问题，一张四行表，逐行写入，最后一行点破 → 每行写入对小节线，写到哪行，左边对象变金 → 3:4 下表放下半屏，对象放上半屏
- 【两千年同一机位】结尾要回到开头时用 → 开头和结尾同一构图，近处黑块不动，只换远处天际线 → 前景层复用，只换背景层 → 3:4 下黑块放左下 1/3，远景放上半屏

## 15 拼尽全力

- 【两块表一动一不动】文案说「努力了却没变化」时用 → 屏上放两个数字，一个涨，一个焊死 → 数字等宽字体，动的用白，死的用红 → 3:4 下两块表放屏幕上 1/4，竖着叠，字放大
- 【包袱埋 143 秒再动】结尾要兑现开头时用 → 开场那块不动的表，到结尾才让它动 → 同一个 UI 组件复用，位置和字体不变，观众才认得 → 3:4 下开场和结尾表放同一位置
- 【一条红线穿过断枝树】要从「大多数没了」转到「你还在」时用 → 灰树长满断枝，一条红线爬到顶，停在「你」 → 分层揭开 drawRange，红线分段停顿 → 3:4 天生合适，竖向更高，屏幕利用率比 16:9 好
- 【幽灵猎豹】讲「威胁已经不在，反应还在」时用 → 主体实色，身后追一个半透明点阵影子 → 影子用网点遮罩把剪影打散 → 3:4 下影子放在主体下方或上方
- 【切线破环】讲换赛道、跳出内卷时用 → 亮点绕环走，突然沿切线飞出屏幕 → 到 t0 由圆周改直线，速度不变 → 3:4 下环放屏下半，切线朝右上，给飞出留长度
- 【人停下才有星空】结尾要从紧张转安静时用 → 人从跑到走到停，抬头，星星才亮 → 跑步周期频率降到 0，星星透明度跟着升 → 3:4 下人放下 1/4，上面留给星星

## 16 涌现

- 【字墙看进化】要演「从笨到聪明」时用 → 同一屏字墙换三次内容：循环词、乱句、一句诗，字变少，意思变多 → 预生成三组文本，打字加旧行变暗 → 3:4 下字墙改窄列，计数器放顶部居中，字号加大到屏宽 1/26
- 【诗碎成片名】片名要出场时用 → 上一段文字碎成粒子，1 秒内聚成片名，闪白 → 两张字图采样配对，顶点里 mix 加噪声 → 3:4 下片名竖排更大，粒子数加到 5000
- 【只认全对的记分牌】文案说「努力看不见」时用 → 上方一排红框写 0，下方一条线一直在好转，线过门槛时框一帧翻成 1 → 分数按阈值切换，不做过渡 → 3:4 下记分牌竖排在上 1/3，线放下 1/2

## 17 时间倒流公式

- 【一个进度条演一辈子】文案说时间、失去、回不去时用 → 把一行字做成墨，化开和聚回只靠一个 melt 值 → 着色器不存状态，纯函数才能零瑕疵倒放 → 改 3:4 把字排两行，烟向上下扩，铺满中间 60% 屏高
- 【数字写到爆屏再换指数】文案要讲多到没概念时用 → 右上数字 10、100、一百万、18 位、30 多位一路缩小，写不下时换成 10^(10^23) → 每 0.4 秒加一档，等宽字体，字号跟位数反比 → 改 3:4 屏窄，写到 15 位就该换指数
- 【公式排队打勾】要说「全都成立，只有一个例外」时用 → 三行公式逐行把 t 换成 (−t)，括号变金，绿 ✓ 踩每秒的拍，然后一句「除了一个。」→ 括号单独一层上色，✓ 落定时全屏抬亮 6 帧 → 改 3:4 公式太长，把人名年份放到公式上方，字号缩到一行放下
- 【把知识铺进世界材质】枯燥的公式要有存在感时用 → 公式铺成吸积盘和粒子流，说到什么就在那个东西上发生 → 盘面按世界坐标采样图集，粒子用 instanced 字符 → 改 3:4 黑洞放上 1/3，盘的近端占下半屏，压迫感更强
- 【静 28 秒换一次爆】文案有「成功了」「明白了」的节点时用 → 爆点前把运动、亮度、音量都压低，爆点同一拍全部翻倍，全片只做两次 → 切点对准配乐能量突跳，用工具量出来再切 → 改 3:4 放射中心放在屏高 40%，下方留给字幕
- 【两个字换世界】结尾要反转时用 → 同一个词补两个字，镜头穿过去换世界 → 「回去」留在原位，「向前」写在竖线另一边 → 改 3:4 两个词改成上下排，分界线改成横线

## 18 镜像分子

- 【镜线劈分身】文案讲同一事物的两面、两种结果时用 → 屏幕正中一条竖线，物体穿过线裂成两个，右边换色 → 父 Group 的 scale.x 取 −1，两边共用旋转角 → 改 3:4 线改成横线，上下分身，或把物体缩到屏宽 40% 以内
- 【一只只熄灭】讲大规模伤害又不能拍惨状时用 → 约 190 只金色小手铺满屏，随机变成暗红，一个字不解释 → 每只一个 delay，亮度和描边按 delay 切换，手有微小随机旋转 → 改 3:4 改成 12 行 14 列，总数差不多，下方留字幕
- 【片名自己演道理】片名要带概念时用 → 「偏心」金青两层错位，2 秒合拢，青字退成一条影，金尘沿镜线炸开 → 两层同一 SDF，offset 用 easeOutQuint 收到 2 像素，留一点错位不要全合 → 改 3:4 字竖排或缩字号，错位方向改成上下
- 【数字真的在跑】文案报一串百分比时用 → 大字从 0 滚到 57，归位，再滚到 99，RUN 进度条跟着走完，粒子同步变色 → 数字由真实序列驱动，字幕先说 57，大字还在涨到 57 的路上 → 改 3:4 大字放屏高 35%，进度条竖排放两边也行
- 【打勾清单留悬念】发现要横跨几十年、几个人时用 → 先亮 3 行清单，只勾第 1 个，后两行问号，40 秒后回来补齐 → 清单同一组件复用，勾是 stroke-dashoffset 动画 → 改 3:4 清单占屏宽 80%，年份放第二行
- 【同一个数字转到人】要从知识跳到情感时用 → 化学段的 0.00005% 在结尾变成「只多了，千万分之五」，粒子场和镜线原样复用 → 同一组件换旁白，观众靠重复自己接上 → 改 3:4 粒子铺满全屏，竖线可保留

## 19 脑内擂台

- 【一帧墨纸】重击、揭晓、入场时用 → 全屏翻成米白纸加黑墨剪影，只有 1 帧，有时加集中线 → 后期按亮度阈值反相，纸色 #ece0cd，先模糊再取阈值，边缘像洇墨 → 改 3:4 把打击点放屏高 40%，集中线中心跟着走
- 【彩虹冲击环】全片最大的两三次撞击时用 → 一个细环从打击点胀到几乎全屏，边缘 RGB 分离 → 环半径 r(t) 用 easeOutExpo，三个通道半径差 3–6 像素，6 帧结束 → 改 3:4 环会先碰到左右边，半径按屏高算，让环被切掉也没关系
- 【比喻做到零件级】用比喻讲科学时用 → 把比喻的每个零件都对上解剖：擂台是突触，灯泡是囊泡，夹子是受体，受体关门时夹子真的变矮 → 零件状态由剧情变量驱动，全片共用一套 uniform → 改 3:4 上下绳距离变长，正好多摆一排灯泡
- 【小人举图表】文案要引实验数据时用 → 上方半透明深色卡片画曲线，下方小人同时演同一件事，右上角写作者年份 → 曲线用 dashoffset 实时画，卡片占屏宽 40%，人不离场 → 改 3:4 卡片放上 1/3，人放下 1/2，刚好分屏
- 【一滴水定住循环】文案从混乱转到平静时用 → 乱线圈越缩越小，上方落下一滴青光，地面涟漪扩开，全场换色 → 涟漪是地面平面上的椭圆环，等比例外扩，颜色整体 lerp → 改 3:4 落点放屏幕中线，水滴路径变长，停顿可以再多半秒
- 【三秒真等三秒】结尾给行动建议时用 → 字幕上方小点 1 秒加 1 颗，同时橙点缩没，观众真的等了 3 秒 → 用真实时长，别压缩 → 改 3:4 小点放在字幕上方，字号比字幕小一半

## 21 花洒下的顿悟

- 【抹雾出字】片名或金句要落地时用 → 竖光 0.33 秒扫过，扫过处雾被抹掉，字留在清玻璃带里 → 清除带上下沿用 fbm 抖动，字和带子共用一个 wipeX → 3:4 里横向距离短，改成带高 1/5 屏、字分两行，或者竖着抹一条
- 【一帧亮网】说到「它开始工作了」时用 → 平时 3 成亮的网在鼓点那一帧亮到顶，0.9 秒退回 → 只提节点 HDR，不碰背景，全片最多三次 → 3:4 节点密度按屏幕面积算，别把横屏的布局拉长，下半屏堆满更好看
- 【灯色就是情节】文案出现「但是」「暗面」时用 → 一盏灯从暖换成冷，画面其它不动，12 秒后再换回来 → uMood 一个变量控灯色和网 alpha，回暖时让字幕同步说结论 → 3:4 灯放上 1/3，字放下 1/3，避开灯心

- 【哪头低哪张网亮】两种状态互相抵消时用 → 跷跷板每秒翻一次，背景跟着在两套图形之间切 → 背景层 alpha 由跷跷板角度驱动 → 3:4 杠杆短，放下 1/4 处，两头标签放上下错开
- 【换句先对焦】长段字幕之间用 → 换句那 0.4 秒水珠变实、水痕下爬，读字时再虚回去 → 一个 uFocus 在清晰图和模糊图之间 mix → 3:4 水痕密度按高度加长，一道爬过全屏约 1 秒

- 【门缝当片名中线】片名只有两三个字时用 → 走廊冲进门、白屏里留一道竖缝，字分列两边 → 竖条 fog=false，白退黑时位置不动 → 3:4 字改上下分列，横缝更合适，或竖缝不变、字高缩到屏宽 30%
