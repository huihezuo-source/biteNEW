## 渲染档次

- 真 3D 约 42%（67 秒）：所有黑洞镜头。证据有三个：1:10 公式流换到另一侧；2:06 机位抬高后盘变成椭圆，上弧跟着变形；公式流在 2:06 绕黑洞转了一整圈。上弧的弯折是真积分还是近似公式，看不出。
- 平面着色器约 54%（85 秒）：蓝字和蓝烟 69 秒，蓝字压光锥 16 秒。其中 0:23–0:35 叠了一层 2.5D 公式卡，有近大远小和失焦。光锥是平面三角，金丝是线段，没有体积。
- 黑场约 4%（5.5 秒）。
- 灯光：没有灯。黑洞和字都靠自发光。盘面左亮右暗，像多普勒亮度差。
- 景深：有，只在黑洞镜头。0:00 右下公式块和 0:42 飞过的公式，离焦点越远越糊。
- 运动模糊：有。0:42 公式卡有拖影，星点是细线。转场再加一层径向模糊。
- 粒子：公式字符流，数量看不清，字符糊成一条；星点约 320 颗（按亮点连通块数）；金丝约 100–150 条。

## 最狠的三个镜头

**一、0:40.4–0:46.4｜「回去」炸开，接着倒放**

- 为什么有冲击：前 28 秒能量只有 2–4 级，运动像素 2%，画面只有一团蓝烟。0:40.4 这一下音量 ×4.6，亮度 Y 34→121，运动像素到 24.7%。蓝换金、静换动、平面换 3D 在同一拍发生。随后 1.5 秒把化了十几秒的字倒放回来，等于把十年收回。
- 怎么做：金字是 SDF 面片，颜色乘 6 进 HDR，靠 Bloom 出光。公式卡用 InstancedMesh，80 个面片，贴图来自 2048 的公式图集，z 从 −60 到 +2 匀速飞，顶点里按 z 算透明度。每帧用累积缓冲叠 32 个子帧，子帧相机在半径 0.03 的镜头圆盘上抖动，对焦面放在金字上，景深和运动模糊一次拿到。转场在后期沿 (uv−0.5) 方向采样 16 次，强度在 40.4 秒取峰值，0.5 秒回零。蓝字是纯函数，倒放只需让 melt 往回走。

```glsl
vec2 p = uv; float d = 0.0;
for (int i = 0; i < 16; i++) {
  p += melt * 0.018 * curl(p * 3.0 + seed + float(i) * 0.1);
  d += texture(textMask, p).r / 16.0;   // 沿流线累加，细丝就是这样出来的
}
vec3 c = ramp(d) * (1.0 + 2.0 * d);     // 深蓝 → #61b0fc → 浅青
```

**二、1:30–1:34｜公式铺成的吸积盘**

- 为什么有冲击：全片只有这 4 秒让黑洞撑满屏。下半屏全是平躺的公式，近处能读，远处糊成细纹，这是比例上的压迫。白流从右上斜插进阴影，把构图切成两半。右下 8 个小光锥一路倒向黑洞，画面在替字幕讲「单行道」。
- 怎么做：全屏片元着色器做光线步进，每条光线走 96–128 步，加速度取 −1.5 h² r / |r|⁵，穿过 y=0 且半径落在盘内时采样盘面。盘面颜色分两层：一层是 fract(r×40) 的同心细纹，一层是世界坐标 (x,z) 采样的公式图集，所以字是平躺的，没有沿圆周弯。亮度乘 (1+0.8·dot(v,n))³ 做左亮右暗。公式流是另一组 instanced 字符面片，沿对数螺线走，离黑洞越近亮度越高，HDR 爆成白线。光锥是 8 个三角面片，第 i 个的倾角 mix(0°,65°,i/7)，半透明金色加 1 像素亮边。

**三、2:00.4–2:12｜「回去」后面补上「向前」，世界翻成光锥**

- 为什么有冲击：前面 24 秒是全片最空的一段，能量 2/9。2:00.3 能量 ×2.4，画面从蓝换成金。中轴竖线把屏幕一分为二，「回去」「向前」各站一边，字幕只说补了两个字，世界跟着换了。金三角从底部张开，方向只有向上，这就是「向前」的画面。
- 怎么做：三角是一张面片，顶点放在底边中点，半角 53°，片元里算到两条边的距离，边上 1 像素 HDR 金线，内部填约 18% 金。金丝是 150 个 instanced 细长面片，从顶点沿射线向外走，长度随速度变，循环发射。竖线用一维噪声抖动 x，下半段加一条 sin 曲线做蓝线。黑洞沿用同一个步进着色器，只把相机俯角抬到约 35°。公式流在盘面内绕一圈再甩出，是对数螺线参数加大。

## 技巧卡

- 【一个进度条演一辈子】文案说时间、失去、回不去时用 → 把一行字做成墨，化开和聚回只靠一个 melt 值 → 着色器不存状态，纯函数才能零瑕疵倒放 → 改 3:4 把字排两行，烟向上下扩，铺满中间 60% 屏高
- 【数字写到爆屏再换指数】文案要讲多到没概念时用 → 右上数字 10、100、一百万、18 位、30 多位一路缩小，写不下时换成 10^(10^23) → 每 0.4 秒加一档，等宽字体，字号跟位数反比 → 改 3:4 屏窄，写到 15 位就该换指数
- 【公式排队打勾】要说「全都成立，只有一个例外」时用 → 三行公式逐行把 t 换成 (−t)，括号变金，绿 ✓ 踩每秒的拍，然后一句「除了一个。」→ 括号单独一层上色，✓ 落定时全屏抬亮 6 帧 → 改 3:4 公式太长，把人名年份放到公式上方，字号缩到一行放下
- 【把知识铺进世界材质】枯燥的公式要有存在感时用 → 公式铺成吸积盘和粒子流，说到什么就在那个东西上发生 → 盘面按世界坐标采样图集，粒子用 instanced 字符 → 改 3:4 黑洞放上 1/3，盘的近端占下半屏，压迫感更强
- 【静 28 秒换一次爆】文案有「成功了」「明白了」的节点时用 → 爆点前把运动、亮度、音量都压低，爆点同一拍全部翻倍，全片只做两次 → 切点对准配乐能量突跳，用工具量出来再切 → 改 3:4 放射中心放在屏高 40%，下方留给字幕
- 【两个字换世界】结尾要反转时用 → 同一个词补两个字，镜头穿过去换世界 → 「回去」留在原位，「向前」写在竖线另一边 → 改 3:4 两个词改成上下排，分界线改成横线

## 放到 A 股片里

借「一个进度条」：把一条账户曲线化成散沙，再倒放回买入那天，字幕说回不去，用来讲止损和复盘。借「数字写到爆屏」讲赚钱的路只有一条、亏钱的路有无数条，右上数字涨到写不下再换指数。借「全片只爆两次」：把能量留给揭晓那一拍，前面敢空 20 秒。
