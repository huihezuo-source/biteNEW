## 世界与用色
- 世界规则：每句话都有读数。屏上任何一句话都能用 bit 量出来，话越能被猜到，字越灰。
- 主色和颜色语义：底色近黑 #06080b（占 86%）。白 = 话本身。灰 = 被猜到、接近 0 bit。红 #e5482f = 信息、意外。绿只在 1:11 的中间方块里露一点。1:34–1:59 全彩细线，这 25 秒是全片唯一的多色段。
- 和他其它片子比，这条独有的是什么：全片没有一个 3D 物体，只靠字、柱、格子和细线。用聊天界面当舞台（气泡、输入法、光标）。结尾是一根闪动的红色光标，和 0:09 输入框里的光标同一种。

## 渲染档次
- 真 3D 0 秒。这条是 2D 加辉光，片子里没有一个有体积的物体。
- 2.5D 约 20 秒（12%）：开头和 2:00 的气泡墙，两层模糊贴片向上漂。
- 平面约 144 秒（88%）：字、柱、折线、方格、细线流场。
- 灯光：没有。发光全靠 Bloom。
- 景深：气泡墙的虚焦是贴片预先模糊的，算假景深。
- 运动模糊：细线有长度，看不出有没有累积模糊。
- 粒子：1400 粒（0:17），细线几千根（数不清），字符雨约 60 列，聚字粒子看不清数量。
- 后期：Bloom 很重，红字光晕半径约 40 px（按 1704 宽算）。暗角轻。没有胶片颗粒可见。闪白 7 次：0:04、0:17、1:30、1:33、2:16、2:25、2:31，亮度分别到 136、244、40、246、72、114、48。

## 最狠的三个镜头
1. **1:30.8–1:38 第 365 格炸开**
   - 时间：1:30.83 最后一格变红，1:33.83 闪白，1:34.5 细线喷出。
   - 为什么有冲击：前 90 秒只有红、白、灰。灰格铺满后画面静止 4.8 秒，运动接近 0。红格只占屏幕约 0.05%，3 秒放大到约 30%，面积差约 600 倍。闪白到 246 之后，几千根彩线从一个点喷出来。配色规则在这一秒被打破，字幕说“所有的颜色，回来”时观众已经看见了。运动像素从 0.7% 跳到 19.3%。
   - 怎么做：网格用片元着色器画圆角方块，`vec2 g=fract(p*vec2(27.,14.))-.5; float d=sdRoundBox(g,vec2(.42),.08);`，每格状态放一张 27×14 的 DataTexture。推近是 `uZoom=exp(k*t)`，缩放中心对准红格。线用 GPU 粒子：约 4000 条，每条 40 段，位置存浮点纹理，每帧 `p+=curl(p*f+t*.1)*dt`，初速度从中心径向炸开并指数衰减。颜色 `hsl(rand(id),.55,.6)`，加法混合，透明度 0.15 上下。

2. **0:00–0:04.2 读数归零**
   - 时间：片子第一帧到 0:04.23 闪白。
   - 为什么有冲击：第一帧就是一句人人说过的话加一个读数。观众还没读完字幕，就看见 9.89 往 0 掉。「第 999 遍」到「第 1000 遍」的那一帧闪白，读数放大 1.5 倍变红，气泡字变灰。这一刻正好是音乐第 2 小节线。
   - 怎么做：`I(n)=-log2(p(n))`，`p(n)` 用 logistic 从 0.001 升到 1。数字每帧写进 CanvasTexture，或走字形图集。气泡用 `sdRoundBox` 加 1 px 亮边。字色 uniform 在 0.6 秒内从白插值到 #6e7075。背景气泡分两层 sprite，预模糊 4 px 和 8 px，向上漂，速度差 2 倍。闪白放在色调映射之后做屏幕混合。

3. **2:01.9–2:06 红气泡和 11.6 bit**
   - 时间：2:01.9 弹出，2:04 读数到顶。
   - 为什么有冲击：舞台和开场完全一样，同样的气泡墙、同样的读数位置，只换了一句话。灰字换成整块饱和红，面积约占屏幕 9%，开场的气泡墙暗下去。读数跟着字数涨，每打一个字跳一次。观众等于在看开场倒放：那边 9.89→0，这边 0.7→11.6。
   - 怎么做：复用开场场景，只改 uniform。气泡底色 `#e5482f`，文字逐字显示，每字到达时用 `-log2(p_i)` 累加读数。气泡外加一层大半径红 Bloom：把气泡 mask 单独模糊 3 次，乘 0.6 叠回。背景气泡透明度从 0.5 降到 0.06。

## 技巧卡
- 【给一句话装读数】要量化一个抽象的东西 → 句子正下方放等宽大读数，跟着次数滚动 → 读数按公式真算，归零那一帧配闪白和音效 → 3:4 气泡放上三分之一，读数在中间，字幕留底。
- 【每个字下面一根柱】要证明两句话不一样 → 逐字排开，每字下一根柱，两句同屏用同一把尺子 → 柱向下长，长柱红光，短柱灰 → 3:4 一行放不下 15 字，改成两行，每行 8 字以内。
- 【一年铺成 365 格】要说日子重复 → 27 列 × 14 行格子，5 格白彗星越扫越快，格子变灰 → 速度从 40 天/秒加到 90 天/秒，读数同步掉到 0 → 3:4 改成 14 列 × 27 行，从上往下填。
- 【最后一格吃掉全屏】要转折 → 全静止后只变一格的颜色，3 秒推到铺满，闪白 → 用指数推近，缩放中心对准那一格 → 3:4 格子竖向够长，红格放下三分之一，推的路更长。
- 【规则破了才给颜色】全片要有一次情绪爆发 → 前面严守单色，转折时一次给全彩，用完收回 → 全彩段只放 25 秒，线细且暗，字幕压得住 → 3:4 流场从底部喷向上方，字幕放中部。
- 【结尾留一根光标】要把行动交给观众 → 全黑，红色光标闪 5 秒，一行小字 → 光标和前面输入框是同一个物件 → 3:4 放屏幕正中，别放底部，抖音底部会被按钮盖住。
