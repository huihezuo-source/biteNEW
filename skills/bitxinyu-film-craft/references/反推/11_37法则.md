## 渲染档次

- 结论：这条是纯 2D 画布，没有任何 3D。全片靠字、线、细圈和火色辉光。任务书说的 3:4、累积缓冲、景深，这条里看不到。本地原片 852×480、30 fps，单帧图是放大 2 倍的。
- 时间占比：真 3D 0 秒，2.5D 0 秒，平面 163 秒。1:31 的旋转只是 2D 变换。
- 灯光：没有。火色字是上下渐变加橙色辉光。
- 景深：没有。
- 运动模糊：看不到。
- 粒子：0:09 竖条碎屑约 200 片（估）。模拟点云能数到约 900 个。1:33 粉尘估 300 粒。2:20 背景细线约 30 条。
- 后期：两层辉光。椭圆暗角一直在，暗处能看到同心色带。逐帧测到 3 次闪：0:17.07、0:29.30、1:33.57，亮度只加 33、5、16，四条里最克制。0:29.3 和 1:33.6 这两下，R、B 通道左右错开约 2 到 4 像素（852 宽下），下一帧就回到 0。两边方向一样，说明是整帧平移，没有径向色差。近黑帧 83.4%。
- 水印：画面左上是 B 站加的「幼笙吖」，上传者字段是比特新语，看不清是不是改名前的水印。

## 最狠的三个镜头

**1. 0:00–0:04 第一帧把答案切开**

- 为什么有冲击：一个数字占半个屏幕，用的是空心描边。开片 0.4 秒内竖光从左扫进来，扫过的地方变实心，然后停在屏宽 36.85%，画面本身就是答案。观众还不知道 37% 是什么，先记住了这个比例。亮的只有「3」，缺的那部分就是后面要讲的 63%。
- 怎么做：把「37%」烘两张贴图，一张实心带上下渐变，一张 1 px 描边，放在同一个面片上。片元里按屏幕 x 切开。`uBeam` 从 0.05 用 easeOutCubic 在 0.4 秒内走到 0.3685。竖光是两层：1 px 白芯加约 5% 屏宽的金雾。「3」的橙色辉光交给 Bloom。

```glsl
float x = gl_FragCoord.x / uRes.x;
float m = step(x, uBeam);                    // uBeam 最后停在 0.3685
vec4 c = mix(texture2D(uLine, vUv), texture2D(uFill, vUv), m);
float d = abs(x - uBeam);
vec3 beam = vec3(1.) * exp(-d * 1400.) + vec3(.9,.65,.3) * .35 * exp(-d * 38.);
gl_FragColor = vec4(c.rgb + beam, 1.);
```

**2. 0:24.3–0:30「跳。」**

- 为什么有冲击：前 5 秒竖条一根根长，全部低于标尺，动作很小，运动像素不到 2%。第 61 根破线的那一帧，竖光直通屏顶，金字 19% 屏高，2 道细圈同时炸开。一个字占一整句的位置。等得越久，这一下越响。
- 怎么做：条的高度在 JS 里预先算好，保证前 60 根都不过标尺。破线时设 `uHit = 1`，用它驱动 4 件事：竖光长度、字弹出（scale 从 1.25 回到 1，easeOutBack）、2 道圆环、RGB 平移。圆环是全屏 quad 上的 SDF。

```glsl
float r = length(uv - uHitPos);
float w = 0.003;
float ring = smoothstep(w, 0., abs(r - uR1)) + smoothstep(w, 0., abs(r - uR2));
col += ring * (1. - uHitAge / .6);
// 后期：col.r = tex(uv + vec2(uShift, 0.)).r; col.b = tex(uv - vec2(uShift, 0.)).b;
// uShift 在 2 帧内从 0.003 回到 0
```

**3. 1:04–1:09 100 次人生翻完，「遗憾的上限」烧出来**

- 为什么有冲击：抽象的 63% 变成 100 张小卡片，一张一张翻红。计数约 4.5 秒跑到 37 : 63，观众看着数字一点点变坏。翻完格子压暗到 10%，金字从左到右烧出来，整屏只剩这 5 个字。
- 怎么做：`InstancedMesh` 100 个面片，每个的迷你竖条图烘进一张图集。打乱 0–99 的下标，前 37 个标金，其余标红，按时间逐个揭开，保证最后正好 37 : 63。边框用圆角矩形 SDF。大字用逐字 reveal，每字 0.12 秒。

```glsl
float t = clamp((uT - aOrder * .045) / .12, 0., 1.);    // aOrder 是打乱后的序号
vec3 edge = mix(vec3(.15,.2,.3), aIsGold > .5 ? GOLD : RED, t);
```

## 技巧卡

- 【竖光切开答案】开场要把结论当悬念放出来时用 → 竖光 0.4 秒扫进来，空心大字被切开，左实右空 → 光停的位置等于答案本身，用 step 切两张贴图 → 改 3:4 时字改两行，光改横光，切在屏高 36.85%
- 【错过的东西碎掉】文案说不能回头时用 → 左边竖条碎成灰屑往下掉，只留眼下这一根 → 每根条拆成小矩形，加重力，从左到右错开 → 改 3:4 时碎屑多落一段，屏高够长
- 【一颗光头把云画成线】要说结果是算出来的时用 → 先灰点云，计数越大越贴线，再一颗光头沿曲线跑，身后变金线 → 点的散布按 1/√N 收紧，线用 drawRange 逐段显示 → 改 3:4 时图占屏宽 86%，曲线高度拉到屏高 40%，计数放图上方
- 【一百次人生摊成格子】要把概率换成次数时用 → 10×10 小卡片随机揭开金或红，计数跑到 37 : 63 → 打乱下标，保证最后比例正好 → 改 3:4 时格子改正方形，上下放字
- 【整张图卷成一点再炸开】要换思路时用 → 图转约 20° 缩成一点，黑一下，白圈炸开 → 组做 rotate 加 scale，easeInCubic，炸开压在小节线上 → 改 3:4 时转角减到 12°
- 【一根线变成下划线】收尾要把话交给片名时用 → 贯穿全屏的金线收缩成片名下面一小段 → 只动 scaleX → 改 3:4 时线上下留足两句字的空间
