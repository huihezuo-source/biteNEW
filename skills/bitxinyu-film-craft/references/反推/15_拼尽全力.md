## 渲染档次

- 真 3D：0 秒。棋盘地有透视，但跑者、棋子、跑道都没有转过身，也没有视差。
- 2.5D：约 45 秒。棋盘地加跑者或棋子约 33 秒，人群 3 层 2 秒，稿纸带投影 10 秒。
- 平面：约 119 秒。图表、网络、跑道、树、台阶、红日、试管、黑场。
- 灯光：没有真实光源。棋子高光是一条固定竖带，逐帧测过位置不变。舞台锥光是加法三角。
- 景深：地面远处变暗变糊，靠渐变和模糊，看不出 z 缓冲。
- 运动模糊：有。跑者和猎豹有明显重影，看起来是累积几帧叠的。地面横向拖影也是。
- 粒子：网络约 40 点，草履虫约 70 只，星星约 40 颗，幽灵猎豹几百个点。
- 后期：字和红色有辉光，四角压暗，全片高对比。闪白带椭圆暗角，色调偏粉灰。

## 最狠的三个镜头

### 1. 36.5 km/h，0.00 m（0:00–0:05）

为什么有冲击：一个人全力跑，一个数字冲到 36.5，另一个数字一直 0.00。不用解释，观众自己就懂了。位移那行是红字。地面在往后滚，人在虚线 x = 0 上不动，像跑步机。第一帧就是片子的全部道理。

怎么做：地面是全屏片元反投影：`z = h/(y - horizon); uv = vec2(x*z, z + speed*t); c = mod(floor(uv.x) + floor(uv.y), 2.0)`，乘距离衰减。跑者是 2D 骨架，关节角 `sin(w*t + phase)`，胶囊 SDF 画四肢，近侧亮，远侧乘 0.4。累积缓冲叠 8 个子帧做重影，再送 Bloom。速度用 `36.5*(1.0 - exp(-t*1.6))`，心率同形。位移固定写 0.00。

### 2. 99%，一条红线（1:33.6–1:44）

为什么有冲击：一下全白之后是全黑。右上角数字冲到 99%，屏幕什么都没有。然后灰色的树从下往上长，全是断枝。最后一条红线一节一节爬到顶，停在一个字：你。前面说的是灭绝，这一下转成了活下来的只有你这条线。

怎么做：进化树预先生成：从底部递归分叉 8 层，约 30 根断在中途，一根走到顶。每条枝用 `drawRange` 按时间揭开，灰线 1 像素。红线单独一条，宽 3 倍，加 Bloom，用 `t` 分段推进，每段之间停 0.1 秒，读起来像一步一步爬。闪白帧压 93.60 秒。百分比用 `1 - exp(-k*t)` 冲到 99。

### 3. 从环上切出去（2:19.6–2:28.5）

为什么有冲击：这个位移表从开场 0.00 到现在，143 秒没动过。亮点绕圈时还是 0.00。一句「方向，是你自己的」，亮点沿切线飞出去，位移开始跳，速度一点没变。观众等这个数字等了全片。

怎么做：亮点角度 `a = w*t`，到 `t0` 改走切线：`p = p0 + v*(t - t0)`，速度大小不变。身后 `LineDashedMaterial` 跟着延长。位移直接等于 `length(p - p0)` 乘系数。跑道是 7 圈椭圆线，外加约 40 个随机小点。切出那一帧压在 143.30 秒。

## 技巧卡

- 【两块表一动一不动】文案说「努力了却没变化」时用 → 屏上放两个数字，一个涨，一个焊死 → 数字等宽字体，动的用白，死的用红 → 3:4 下两块表放屏幕上 1/4，竖着叠，字放大
- 【包袱埋 143 秒再动】结尾要兑现开头时用 → 开场那块不动的表，到结尾才让它动 → 同一个 UI 组件复用，位置和字体不变，观众才认得 → 3:4 下开场和结尾表放同一位置
- 【一条红线穿过断枝树】要从「大多数没了」转到「你还在」时用 → 灰树长满断枝，一条红线爬到顶，停在「你」 → 分层揭开 drawRange，红线分段停顿 → 3:4 天生合适，竖向更高，屏幕利用率比 16:9 好
- 【幽灵猎豹】讲「威胁已经不在，反应还在」时用 → 主体实色，身后追一个半透明点阵影子 → 影子用网点遮罩把剪影打散 → 3:4 下影子放在主体下方或上方
- 【切线破环】讲换赛道、跳出内卷时用 → 亮点绕环走，突然沿切线飞出屏幕 → 到 t0 由圆周改直线，速度不变 → 3:4 下环放屏下半，切线朝右上，给飞出留长度
- 【人停下才有星空】结尾要从紧张转安静时用 → 人从跑到走到停，抬头，星星才亮 → 跑步周期频率降到 0，星星透明度跟着升 → 3:4 下人放下 1/4，上面留给星星
