## 世界与用色

- 世界规则：全片只有一张会抖的网，黑洞和吵架都是往网上砸东西，字也骑在波上走。
- 主色和颜色语义：底色深蓝黑，#060812 到 #0e1222。网平时只有约 10% 亮度，波到哪里亮到哪里，中心白蓝，外围转暗金。白点是你，金点是 TA。暗红气泡是吵架的话。金色还用来标时间和能量（亿年计数、3 个太阳、× 50）。干涉环是暗金 #6b533b，亮起来才转亮金。
- 和他其它片子比，这条独有的是什么：抽 12 帧和第 9 秒比，星空位移全是 0 像素，一张静止星图从头用到尾。没有相机运动，所有动感都来自网。科学事件和人事用同一套动作演两遍：0:00 黑洞互绕相撞，1:04 你和 TA 互绕相撞。

## 渲染档次

- 结论：这条是四条里 3D 感最强的，用的是真透视的线框网。没有面，没有光照，相机不动。任务书说的 3:4、累积缓冲、景深，这条里看不到。本地原片 852×480、30 fps，单帧图是放大 2 倍的。
- 时间占比：按“有体积、有受光面、相机在动”算，真 3D 是 0 秒。2.5D 约 111 秒（透视线框网，占 68%）。平面约 47 秒（0:37–0:55 的横条、星图、LIGO 示意，0:56–1:03 平视网，1:42–2:03 干涉环，占 29%）。其余是黑场。
- 灯光：没有光照。亮度直接来自波高，平的地方约 10%，波峰过曝。
- 景深：没有真景深。星星分两种，小而实、大而虚，这是假的。
- 运动模糊：看不到。黑洞高速绕转时环还是清楚的。
- 粒子：星空约 480 颗，静止，只淡入淡出。网格估 80×60 格，门那段更粗，折角看得见。
- 后期：两层辉光。椭圆暗角压在最上层。逐帧测到大闪 7 次：0:04.27、0:14.93、0:17.07、1:08.27、1:33.87、1:47.60、2:25.07，平均亮度 239、68、246、127、247、89、130。色调映射看不清。近黑帧 3.6%，四条里最低。
- 水印：画面左上是 B 站加的「幼笙吖」，上传者字段是比特新语，看不清是不是改名前的水印。

## 最狠的三个镜头

**1. 0:14.93–0:17.5 门一关，地面起波，闪白出「余波」**

- 为什么有冲击：门缝收成 1 条线，光束跟着收，动作很小。门底闪一下，波从门脚起，2 秒铺满屏宽。音乐这时是抽空的，17.07 副歌一进，平均亮度从 40 左右冲到 246，大字高 36% 屏高。小动作和大后果的比例就在这 2 秒里。
- 怎么做：网用 `LineSegments`，顶点在 vertex shader 里算高度。相机抬高 20° 左右，看网的前半部分。亮度和波高绑定，平网几乎看不见。大字用高斯模糊半径从 24 px 走到 0，放在 Bloom 之前。

```glsl
float r = distance(p.xz, uSrc);
float front = uC * (uT - uT0);
float env = exp(-1.2 * max(r - front, 0.)) * exp(-.35 * max(front - r, 0.));
float h = uAmp * env * sin(uK * (r - front));
p.y += h;
vBright = .10 + 6. * abs(h);                       // 平的地方只有 10%
vColor = mix(vec3(.85,.9,1.), vec3(.8,.65,.4), smoothstep(.2, .9, r / uR));
```

**2. 1:30–1:42「他错了。」到 LIGO 巨网**

- 为什么有冲击：前 4 秒全屏压到快看不见，音乐也抽空，高频掉 15 dB。「他错了。」说完，1:33.87 闪白到 247。闪完机位换到贴着网面，3 道波峰横贯全屏，比例从 2 个小点变成铺满 3/4 屏的一片布。前 90 秒的网大多是俯看，这一刻才贴着网面。
- 怎么做：同一张网换相机，高度压到网宽的 8%，俯角约 12°。波改成平面波 `sin(k * z - w * t)` 叠 2 道，外加一层大尺度起伏。远端用线性雾淡出。峰线亮度用 `pow(height, 3.)`，只让最高处过曝。LIGO 字放在网上方，不贴网。

```glsl
float h = .05 * sin(1.4 * p.z - 1.1 * uT) + .03 * sin(.6 * p.x + 2. * p.z - .7 * uT);
p.y += h;
vBright = .18 + 8. * pow(clamp(h / .08, 0., 1.), 3.);
vFog = smoothstep(4., 14., -mvPos.z);              // 远处淡出
```

**3. 2:13–2:20 打字说对不起，平息圈从你推到 TA**

- 为什么有冲击：满屏都是波，全片网最密的时候，屏上只有 9 个字在一个一个打出来，光标在闪。打完不到 1 秒，圆内的网全部变平。圆边走了 2.5 秒才到 TA，TA 从金变白亮一下。文案说「抚平」，屏上就是平了一块。
- 怎么做：高度函数乘一张以「你」为圆心的遮罩。圆内亮度也压低，只留很弱的平网。TA 的颜色用 `smoothstep` 判断圆边是否到达。

```glsl
float d = distance(p.xz, uYou);
float calm = smoothstep(uR - .35, uR + .35, d);    // 圆内 0，圆外 1
p.y += h * calm;
vBright = mix(.08, base, calm);
// TA：float hit = smoothstep(uR - .2, uR + .2, distance(uYou, uTA)); 反向取 1. - hit 做颜色和光晕插值
```

## 技巧卡

- 【话当石头砸进网里】文案说一句话伤人时用 → 气泡从上方掉下，砸到网上起环波 → 气泡 y 用重力加回弹，落点写进波源数组 → 改 3:4 时网的视角抬高，气泡落在屏高 45%
- 【字骑在波上走】文案列举后果一件件扩散时用 → 每个标签绑在一道环波上，跟着往外走、变淡 → 标签位置等于波源加方向乘 c(t−t₀)，alpha 随半径衰减 → 改 3:4 时标签走上下方向，横向不够宽
- 【卡尺在跳，人没动】文案说距离变了但没人动时用 → 平视网格横压竖拉，两点下方卡尺跳数，头顶标 Δv = 0 → x 乘 1+a·sinωt，y 乘 1−a·sinωt，a 随时间放大 → 改 3:4 时两点上下摆，卡尺竖放
- 【平息圈】文案说被抚平时用 → 从一个人起一个圆，圆内高度归零，圆边扫到另一个人 → h 乘 smoothstep(R−w, R+w, d) → 改 3:4 时圆从屏幕下方推到上方
- 【同一个动作演两遍】科学事件要对上人事时用 → 0:00 黑洞互绕相撞，1:04 两个人互绕相撞，同样的加速和闪 → 共用 orbit(t) 函数，只换外观和标签 → 改 3:4 时绕转半径限制在屏宽 30% 以内
- 【闪完贴近网面】要换尺度时用 → 闪白遮住切换，相机贴到网面，峰线横贯全屏 → 相机高度压到网宽 8%，远端用雾 → 改 3:4 时地平线提到屏高 75%，下方多放网
