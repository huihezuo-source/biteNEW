## 世界与用色

- 世界规则：每样东西身上都有一个没人管就往前走的进度条，有人出力它就倒回去。
- 主色和颜色语义：底色近黑 #07080a。暖金 #ffe48b 表示还有人管、还有能量（窗光、硬币正面、体温 37.0°C、做功）。冰蓝白 #dbffff 表示凉透了（变冷、疏远）。绿 #b0f98d 表示荒野接管。灰蓝 #657d8e 表示室温（22.0°C）。玫红只给花和右边那颗光点，代表感情。
- 和他其它片子比，这条独有的是什么：没有一张贯穿全片的底图，靠 5 组物件串起来（房间、城市、两颗光、粒子、人形）。每组都出现两次，一次坏，一次修。开场相框里的两颗小光点，就是 0:09 那两颗光。聊天记录的第一条日期是 2016.05.20，最后一组是 2023.02.14，一个是 520，一个是情人节。

## 渲染档次

- 结论：这条是 16:9 的 2D 画布片，只有两段带透视，一段点云是真 3D 投影。任务书说的 3:4、累积缓冲、景深，这条里看不到。本地原片 852×480、30 fps，单帧图是放大 2 倍的，细节到此为止。
- 时间占比：真 3D 约 23 秒（点球 2:08–2:31，占 13%）。2.5D 约 18.5 秒（房间 2 段 10 秒，地板 8.5 秒，占 11%）。平面约 129 秒（占 76%，含字幕页和尾声）。
- 灯光：没有光照计算。窗光是半透明梯形加泛光，胸口橙光是径向渐变。
- 景深：没有。
- 运动模糊：看不到。落球和粒子都是实点。
- 粒子：「熵」字估 3000–5000 颗；胸像能数到约 2460 颗；地板灰能数到 4100 颗以上；点球整球估 1500–2000 颗。全部是圆点加色混合。
- 后期：字和亮物有两层辉光，紧贴字边一层，外面一层约字高的 1/3。椭圆暗角压在最上层，所以闪白四角是灰的。逐帧测到 5 次闪：0:17.07、1:33.87、1:40.27、2:20.80、2:31.47，平均亮度 242、58、56、103、58。暗处能看到同心色带。色调映射看不清。近黑帧占 32.8%。

## 最狠的三个镜头

**1. 0:16.9–0:20.4「熵」字从闪白里收出来**

- 为什么有冲击：前 6 秒音乐抽空，画面只剩 2 颗小冰晶。0:17.0 全黑，下一帧平均亮度跳到 242。主体从 2 个小点变成占屏高 54% 的一个字，粒子云 0.2 秒收完，节奏就是一拍。
- 怎么做：`THREE.Points` 放 5000 个点。离屏 canvas 画「熵」，取像素，按亮度拒绝采样得到 `aTarget`。`aStart` 在屏幕椭圆内随机。闪白是全屏 quad，暗角 pass 排在它后面，四角才会灰。

```glsl
// vertex
float k = easeOutExpo(clamp((uT - aDelay) / 0.25, 0., 1.));
vec3 p = mix(aStart, aTarget, k) + curl(aTarget * 3. + uT) * 0.006 * (1. - k * .7);
gl_PointSize = aSize * (1. + 2. * (1. - k));
// fragment：高斯圆点，AdditiveBlending，toneMapped=false，交给 Bloom
// flash：alpha = exp(-(uT - t0) / 0.05)
```

**2. 1:19–1:33.8 聊天记录降到室温，字散开**

- 为什么有冲击：时间戳跳 7 年，气泡从两行长句缩到一个「嗯」。这 10 秒运动像素只有 0.3%，有画面的段落里最低。1:30 字突然散开，字号没变，还能认出「想」「你」。接着大字「疏远。」，和开头的「变冷。」同位置。
- 怎么做：气泡框用圆角矩形 SDF 片元着色器，`uWarm` 从 1 走到 0，`mix(gray, gold, uWarm)`。每个字一个 `InstancedMesh` 面片，uv 指字符图集，`aHome` 是排版位置。散开时只动位置，不转不缩。

```glsl
vec2 off = uScatter * (aDir * aLen + vec2(snoise(aHome * 2. + uT), snoise(aHome * 2. - uT)) * .08);
pos.xy = aHome + off;
```

**3. 1:40.27–1:46 一根光条把地扫干净**

- 为什么有冲击：片子几乎全是平的，这里突然压到低机位，地板占屏下 45%。一根光条 3.5 秒推过 4000 多颗灰，窗亮和 W 归 1 同时发生。文案说「用力气，对抗概率」，屏上就是一个出力的动作。
- 怎么做：`PerspectiveCamera` 贴近地面，灭点放在屏高 45%。地面 `PlaneGeometry`，片元里按世界坐标画地砖线，用 `step(vWorld.x, uSweep)` 只显示扫过的部分。灰粒是 `Points`，在 vertex 里判断。W 用 `pow(10., 6. * (1. - p))` 取整显示，p 到 1 时写死 1。

```glsl
// 灰粒 vertex
if (aPos.x < uSweep) {
  float pile = pow(aRand, 3.) * .05;          // 堆在光条前沿
  pos.x = uSweep + pile;
  vAlpha = 1. - smoothstep(0., .6, (uSweep - aPos.x)); // 推远了就消失
}
// 地砖 fragment
vec2 g = abs(fract(vWorld.xz * 8.) - .5) / fwidth(vWorld.xz * 8.);
float line = 1. - min(min(g.x, g.y), 1.);
col += line * .25 * step(vWorld.x, uSweep);
```

## 技巧卡

- 【一个进度条走完一间屋】文案说放着不管会怎样时用 → 3 秒里窗变暗、花垂头、灰堆满、相框歪、蛛网长，全部同时发生 → 所有动画吃同一个 decay（0 到 1），各自用 smoothstep 错开 0.1 → 改 3:4 时房间收窄，窗和桌竖着排，字幕放在地板上
- 【同一批物件倒放一次】文案先讲坏、后讲修时用 → 房间、城市、两颗光、粒子前半段坏一次，后半段按原构图修回来 → 场景写成 scene(decay)，修的时候 decay 从 1 走回 0 → 改 3:4 时两次构图不能变，观众要认得出
- 【字也变成乱的样子】文案说回到最大概率的样子时用 → 气泡框退掉，字按原字号漂散 → 字符面片加噪声位移，不转不缩 → 改 3:4 时聊天区占屏宽 80%，上下多留 30% 给字漂
- 【把数真算出来打满一行】文案说多到数不清时用 → 正中一行 30 位真实数字，先滚后定 → 用大数算 C(100,50) 逐位显示 → 改 3:4 时拆成 3 行，每行 10 位，字号不小于屏宽 5%
- 【光条扫地数字归一】文案说出力把乱压回去时用 → 光条推走粒子，身后露出整齐的格子，计数掉到 1 → 粒子用 uSweep 判定，计数用指数插值 → 改 3:4 时光条从下往上推，路程更长
