## 世界与用色

- 世界规则：屏幕正中立一条竖直镜线，左边一半是左手，右边一半是右手，任何东西过线就变成自己的镜像。

## 渲染档次

- 真 3D 约 25%（40 秒）：球棍分子和地球。分子转动时前后遮挡正确，后排原子更暗更小，球有高光和边缘光。
- 粒子点云约 17%（27 秒）：1:33.8–1:44、2:08–2:24。粒子大小分两档，像景深，也可能是两层精灵，分不清。
- 平面发光线描约 10%（16 秒）：两只手。手翻面没有透视，宽度直接压到 0，所以判定是 2D 图层。
- 平面图表和字卡约 48%（77 秒）：胶囊、天平、清单、曲线、试管、图标、片名。
- 灯光：分子有左上方主光，高光点在球的左上；边缘金色描边很可能是菲涅尔。地球右上有一块亮区。其余全是自发光。
- 景深：弱。蛋白质上下两条链更暗更小，看不出明显焦外。
- 运动模糊：0:02 分身有 5–6 层残影，层数少，看得出是一层层叠的。
- 粒子：金尘约 200 颗；数字段约 1400 颗；八十亿段约 2100 颗灰白、约 1500 颗金（按亮点连通块数，实际可能更多）。
- 后期：字和手有 Bloom，暗角重。每次切镜抬亮 4–8 帧，暖灰色，中间亮四角暗，指数回落。片名、「50 年」、0.00005% 三处抬亮最强。胶片颗粒看不清。

## 最狠的三个镜头

**一、0:01.6–0:04｜镜线劈出第二个分子，右边染红**

- 为什么有冲击：片子第 1.6 秒就给出全片规则。一个物体占满屏，一条线从天而降，分成两个，构图从中心一下变成左右对称。比例从 60% 屏高缩到约 25%，留出左右两半。0:03.7 能量 ×2.6，右边染红，字幕同时放大一倍。三句字幕 4 秒讲完一场悲剧的结论。
- 怎么做：原子用 InstancedMesh 的球，键用圆柱，材质 MeshStandard，加 onBeforeCompile 注入 rim：pow(1−dot(N,V),3)×金色。镜像用一个父 Group，scale.x = −1，两个 Group 共享同一个旋转角，左右才严格镜像。分身时位置 x 从 0 走到 ±0.28 屏宽，scale 从 1 到 0.42，用 easeOutExpo，0.5 秒。残影是累积缓冲只开 6 个子帧。右侧材质加 uTint，0.5 秒内 mix 到玫红，rim 同步变色。镜线是 1 像素 HDR 线段加 7 个随机大小的精灵。抬亮在后期加 vec3(.25,.22,.18)×vignette×exp(−f/3)，f 是切镜后的帧数。

**二、1:53–1:56｜一个亮点吞掉地球**

- 为什么有冲击：一个白点只占地球面积百分之一，2 秒后整颗星球变金，比例反差就是道理本身。锋面亮度最高，不规则，像火线。字幕「被一遍遍复制，直到覆盖整个星球」和动作同步完成。
- 怎么做：球体 64×64 段，片元里算 n·seed 的夹角 d。锋面半径 r(t) 用 easeInOutCubic 从 0 走到 π，时长 2 秒。

```glsl
float d = acos(dot(n, seedDir)) + 0.12 * fbm(n * 6.0);  // 噪声让锋面不规则
float g = smoothstep(r + 0.03, r - 0.03, d);            // 已占领区域
vec3 base = mix(oceanBlue, gold * (0.7 + 0.5 * fbm(n * 3.0)), g);
base += hdrGold * exp(-pow((d - r) / 0.05, 2.0));       // 前沿亮线，进 Bloom
```

大气是一个略大的球，只画背面，颜色乘 pow(1−dot(N,V),4)。

**三、2:16.5–2:24｜满屏变金，然后塌成一点**

- 为什么有冲击：先给满屏数量，约 1 秒全场翻金，亮度翻倍。接着 1.3 秒把上千颗点全部卷进一个点，从最多到最少。这一下把「八十亿分之一」和「唯一」做成同一个动作。音乐能量到 2:24.9 才抬（×2.7），塌缩这段是压着的，音量留给两只手。
- 怎么做：2000 个点的 THREE.Points，attribute order 取 0–1 随机数，顶点里 gold = smoothstep(uCopy−0.05, uCopy, order)，uCopy 在 1 秒内扫过。左半边点的位置由右半边镜像生成，所以图案左右对称。塌缩时对每点做 p = rotate(p, k·t/(0.2+|p|))，再 p = mix(p, center, easeInCubic(t))，近中心的点转得快，自然卷成旋臂。最后换成一个 HDR 精灵加径向渐变暖晕。

## 技巧卡

- 【镜线劈分身】文案讲同一事物的两面、两种结果时用 → 屏幕正中一条竖线，物体穿过线裂成两个，右边换色 → 父 Group 的 scale.x 取 −1，两边共用旋转角 → 改 3:4 线改成横线，上下分身，或把物体缩到屏宽 40% 以内
- 【一只只熄灭】讲大规模伤害又不能拍惨状时用 → 约 190 只金色小手铺满屏，随机变成暗红，一个字不解释 → 每只一个 delay，亮度和描边按 delay 切换，手有微小随机旋转 → 改 3:4 改成 12 行 14 列，总数差不多，下方留字幕
- 【片名自己演道理】片名要带概念时用 → 「偏心」金青两层错位，2 秒合拢，青字退成一条影，金尘沿镜线炸开 → 两层同一 SDF，offset 用 easeOutQuint 收到 2 像素，留一点错位不要全合 → 改 3:4 字竖排或缩字号，错位方向改成上下
- 【数字真的在跑】文案报一串百分比时用 → 大字从 0 滚到 57，归位，再滚到 99，RUN 进度条跟着走完，粒子同步变色 → 数字由真实序列驱动，字幕先说 57，大字还在涨到 57 的路上 → 改 3:4 大字放屏高 35%，进度条竖排放两边也行
- 【打勾清单留悬念】发现要横跨几十年、几个人时用 → 先亮 3 行清单，只勾第 1 个，后两行问号，40 秒后回来补齐 → 清单同一组件复用，勾是 stroke-dashoffset 动画 → 改 3:4 清单占屏宽 80%，年份放第二行
- 【同一个数字转到人】要从知识跳到情感时用 → 化学段的 0.00005% 在结尾变成「只多了，千万分之五」，粒子场和镜线原样复用 → 同一组件换旁白，观众靠重复自己接上 → 改 3:4 粒子铺满全屏，竖线可保留

## 放到 A 股片里

借「镜线」：同一根 K 线，线左边是机构看到的，线右边是散户看到的，用镜像把信息差演出来。借「一只只熄灭」讲散户账户：200 个小账户图标铺满屏，一轮行情后逐个变暗，一个字不解释。借「同一个数字转到人」：讲仓位时的 1%，结尾回到一个具体的人身上。
