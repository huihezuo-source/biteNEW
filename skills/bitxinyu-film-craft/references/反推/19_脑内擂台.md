## 渲染档次

- 真 3D：没有能确认的。0:04 玻璃碎片有高光和近大远小，约 6 秒，可能是 3D，也可能是带贴图的多边形，分不清。
- 2.5D 约 73%（96 秒）：擂台主场。人、绳、灯泡、神经树分层，镜头有推拉和约 ±3° 的滚转，上下绳随之倾斜。绳的鱼眼弯曲是画出来的，看不出真实透视。
- 点云约 8%（11 秒）：0:10.5–0:15、2:00–2:06 的神经森林。退镜时分层缩放，看不出是不是真 3D 点云。
- 平面约 17%（22 秒）：片名、循环圈、结尾。其余约 2% 是黑场和淡出。
- 灯光：线条自发光加 Bloom。1:52–1:57 五道体积光是半透明四边形。人脚下有一片地面光斑，跟着人走，算假反光。
- 景深：背景神经树糊，灯泡离焦成带圈的光斑，这是分层模糊。
- 运动模糊：快动作时人带 2–3 层残影，层数看得出来。
- 粒子：每次重击 20–60 颗火花；神经森林约 1900 颗亮点（按亮点连通块数）。
- 后期：字和绳边缘有 RGB 色差，重击时加大。彩虹冲击环 3 次（0:16.5、0:32.83、1:05.2）。墨纸帧 14 次共 15 帧（按纸色 #ece0cd 逐帧数的），时间：0:01.23、0:03.00、0:04.03（2 帧）、0:04.53、0:10.63、0:16.70、0:19.17、0:25.43、0:28.73、1:05.30、1:05.93、1:21.50、1:37.63、1:45.73。前 29 秒就用了 9 次，0:29–1:05 一次没有，把第二回合的拳头留给 1:05。线条有手抖感。胶片颗粒看不清。

## 最狠的三个镜头

**一、0:01.2–0:04.4｜三拳打裂屏幕，第四拳打碎**

- 为什么有冲击：片子开头 3 秒就给了动作，屏幕本身成了挨打的东西。每拳一张裂纹，节奏 1 秒 1 下，第 4 拳不再加裂纹，整面碎掉，这是把预期打破一次。裂纹是白细线，碎片是半透明面，材质突然变厚。字幕大到压在画面中下，也一起碎了。
- 怎么做：裂纹用泰森多边形（Voronoi）的边加径向主裂，以击打点为圆心生成，按距离逐段 draw。碎片用同一张 Voronoi 切出约 60 个多边形，ShapeGeometry 挤出很薄的厚度，MeshPhysical 打高透明度和菲涅尔，爆开时每片沿径向 v=dir×(0.6+rand) 飞，加随机旋转，1 秒后减速悬停。字幕做成同样的切片贴图一起飞。金人是骨骼折线，线宽从关节到四肢末端收细，进 HDR 让 Bloom 出光，残影是保留前 2–3 帧的骨架，透明度递减。

**二、0:10.6–0:14.5｜一拳炸开，退到整个大脑**

- 为什么有冲击：刚刚 3 个小人打得满屏，一退，这场架成了一个亮点，字幕同时说「上百万亿个」。比例从擂台的米级感觉退到一颗头，3.5 秒跨 3 个尺度。然后白线写出一张侧脸，观众才发现自己一直在这个人脑子里。
- 怎么做：三层点云叠着做。第一层神经枝用 L 系统生成约 3000 段线，第二层亮点约 2000 颗 Points，第三层是擂台缩略纹理。相机沿 z 指数后退，z(t)=z0·exp(k·t)，这样缩放在视觉上匀速。退到一定距离把点按高斯分布收进头部 SDF 内：p = mix(p, sampleInsideHead(id), s)。侧脸是一条预先画好的贝塞尔路径，用 dashoffset 写出来，HDR 白线。结尾 2:00 复用这组镜头，只换文字。

**三、1:35–1:39.5｜白色的「你」一鞭入场**

- 为什么有冲击：白人在 1:03 被打飞后躺了半分钟，观众已经忘了他。青人向右让开，一条长弧从屏幕右侧甩到左下角，把白人拉起来。这一拍叠了墨纸帧，1 帧里全屏翻成米白，黑色长弧横跨整个画面，下一帧回到黑底，白人站着发光。字幕只有四个字说破：「不是选手，是你。」
- 怎么做：长弧是一条三次贝塞尔，控制点从青人的手甩到白人，线宽两头细中间粗，0.4 秒内甩出。白人亮度从 1 升到 4，进 Bloom。墨纸帧在后期做，只开 1 帧：

```glsl
if (uInk > 0.5) {                     // 重击那 1 帧
  float l = dot(col, vec3(.3,.6,.1)) + 0.15 * noise(uv * 40.0);
  float ink = smoothstep(0.12, 0.25, l);   // 亮的变墨，暗的变纸
  col = mix(vec3(0.925,0.878,0.804), vec3(0.03), ink);   // 纸 #ece0cd
  col *= 1.0 - 0.9 * focusLines(uv, hitPoint) * step(0.5, uFocus);  // 集中线
}
```

这样亮线全变黑墨，黑底全变米白。集中线和墨点是单独一层，只在打击时叠。人形变实心是因为先做了一次膨胀，线条被 Bloom 撑胖后再取阈值。

## 技巧卡

- 【一帧墨纸】重击、揭晓、入场时用 → 全屏翻成米白纸加黑墨剪影，只有 1 帧，有时加集中线 → 后期按亮度阈值反相，纸色 #ece0cd，先模糊再取阈值，边缘像洇墨 → 改 3:4 把打击点放屏高 40%，集中线中心跟着走
- 【彩虹冲击环】全片最大的两三次撞击时用 → 一个细环从打击点胀到几乎全屏，边缘 RGB 分离 → 环半径 r(t) 用 easeOutExpo，三个通道半径差 3–6 像素，6 帧结束 → 改 3:4 环会先碰到左右边，半径按屏高算，让环被切掉也没关系
- 【比喻做到零件级】用比喻讲科学时用 → 把比喻的每个零件都对上解剖：擂台是突触，灯泡是囊泡，夹子是受体，受体关门时夹子真的变矮 → 零件状态由剧情变量驱动，全片共用一套 uniform → 改 3:4 上下绳距离变长，正好多摆一排灯泡
- 【小人举图表】文案要引实验数据时用 → 上方半透明深色卡片画曲线，下方小人同时演同一件事，右上角写作者年份 → 曲线用 dashoffset 实时画，卡片占屏宽 40%，人不离场 → 改 3:4 卡片放上 1/3，人放下 1/2，刚好分屏
- 【一滴水定住循环】文案从混乱转到平静时用 → 乱线圈越缩越小，上方落下一滴青光，地面涟漪扩开，全场换色 → 涟漪是地面平面上的椭圆环，等比例外扩，颜色整体 lerp → 改 3:4 落点放屏幕中线，水滴路径变长，停顿可以再多半秒
- 【三秒真等三秒】结尾给行动建议时用 → 字幕上方小点 1 秒加 1 颗，同时橙点缩没，观众真的等了 3 秒 → 用真实时长，别压缩 → 改 3:4 小点放在字幕上方，字号比字幕小一半
