## 世界与用色

- 世界规则：屏幕上的一切都是一条线，线的起伏就是你的心跳，最后这条线变成地平线。
- 主色和颜色语义：底色紫黑 #070409。玫红 #f53487 是上头：心电线、B 鸽子、放电高柱、忽冷忽热的 TA。米金约 #f0d9a8 是稳定：A 鸽子、一直秒回的 TA。青灰约 #6fb8c8 是底噪、信号和比预期差。紫 #c360fd 是头像和老虎机外壳。太阳段的橙褐 #694137 是安全感，只在最后 30 秒出现。
- 和他其它片子比，这条独有的是什么：全片亮度压在 10–20，2:10 起跳到 36–41，翻了 2 到 4 倍，大面积暖色也是这时才第一次出现。前 130 秒的暗和冷，都在给最后这 30 秒蓄力。

## 渲染档次

- 结论：这条是纯 2D 霓虹画布。神经元、老虎机、日出全是平面图形加辉光。任务书说的 3:4、累积缓冲、景深，这条里看不到。本地原片 852×480、30 fps，单帧图是放大 2 倍的。
- 时间占比：真 3D 0 秒，2.5D 0 秒，平面 161 秒。
- 灯光：没有。太阳是过曝圆盘加径向渐变，水面是竖向渐变加横线。
- 景深：没有。
- 运动模糊：只有老虎机转轮有，符号竖向拖影。其它地方看不到。
- 粒子：基本没有。主角是线，放电散点约 12 行。
- 后期：霓虹辉光两层，线芯白、外圈玫红。椭圆暗角压在最上层，软闪看着是灰白椭圆。逐帧测到 11 次闪，四条里最多：0:01.60、0:11.97、0:17.07、0:34.13、0:42.67、0:44.80、1:11.47、1:33.87、1:52.53、1:54.67、2:10.13，平均亮度 50、82、249、74、64、109、83、111、59、113、88。其中 0:34、0:42、0:44、1:52、1:54 都压在小节线上，误差在 0.2 秒内。这些闪就像全片的心跳。近黑帧 62.8%。

## 最狠的三个镜头

**1. 0:04–0:13「你等了」到消息弹出**

- 为什么有冲击：一个白色大钟 8 秒走完 4 小时 44 分，心跳落回 90。音乐这时抽空。0:11.97 全屏软闪，回复弹出来，内容只有「刚看到。明天好不好」，R 波窜到平时约 2 倍，BPM 从 90 到 138 不到 1 秒。观众的等待和屏上的心跳是同一件事。
- 怎么做：心电线放在全屏片元着色器里算距离。每一拍的幅度放进一张 1D 贴图或 uniform 数组，消息到达时改写当前那一拍。聊天框是另一层，用圆角矩形 SDF 把线压暗。0:14 之后把压暗系数从 0.2 走到 1，就成了线压过框。

```glsl
float x = uv.x + uT * uSpeed;
float beat = floor(x / uPeriod);
float amp = texture2D(uBeats, vec2(beat / 256., .5)).r;   // 消息到达时写入 2.0
float y = ecg(fract(x / uPeriod)) * amp;                  // P-QRS-T 分段函数
float d = abs(uv.y - .5 - y);
vec3 col = PINK * (exp(-d * 90.) + .35 * exp(-d * 14.));
col *= smoothstep(uHead - .95, uHead, uv.x);              // 尾巴淡出
```

**2. 1:17–1:33.8 老虎机差一格，接下拉刷新**

- 为什么有冲击：这里是全片颜色最多的一段，前面都是黑底细线。3 列符号带拖影转动，第 3 列的心停在中线下方 1 格，圆圈圈住。然后拉杆往下这个动作直接换成手指往下拖，文案只问一句「像不像」，屏上已经演完了。
- 怎么做：每列是一张符号图集，`uv.y += uOffset`。拖影按速度沿 y 采样 8 次取平均。停下用 easeOutBack，第 3 列的目标值故意少 1 格。拉杆绕底部旋转。信息流卡片组整体跟手指下移，松手回弹，新卡片从顶部插入，填粉色。

```glsl
vec3 c = vec3(0.);
for (int i = 0; i < 8; i++) {
  float o = uSpeed * (float(i) / 7. - .5) * .06;
  c += texture2D(uReel, vec2(vUv.x, fract(vUv.y + uOffset + o))).rgb;
}
c /= 8.;
```

**3. 2:08–2:36 平线变地平线**

- 为什么有冲击：前 2 分钟这条线代表无聊，全片都在说它没有尖峰。线的位置一像素没动，2:10.13 软闪一下，天和水在它周围长出来，亮度从 10 跳到 38。文案同时翻转：「这条平平的线——有一个名字，叫安全感。」图表直接变风景，中间没有切镜。
- 怎么做：线保持在屏高 59%。全屏背景 shader 用 `uDawn`（0 到 1）控制。上半是 3 段竖向渐变，下半是水面，水里的太阳倒影用横线纹。太阳 `uSun` 从地平线下升起，地平线以下裁掉。2 颗小白点在 2:21 淡入，放在太阳左边，和屏幕中线隔开约 20% 屏宽。

```glsl
float h = uv.y - .41;                                   // 地平线，uv.y 从下往上算，等于从上往下 59%
vec3 sky = mix(vec3(.42,.26,.22), vec3(.07,.04,.05), smoothstep(0., .45, h));
vec3 sea = mix(vec3(.31,.2,.16), vec3(.03,.02,.03), smoothstep(0., .22, -h));
vec3 col = (h > 0. ? sky : sea) * uDawn;
float s = 1. - smoothstep(uR - .004, uR, distance(uv * vec2(1.78, 1.), uSunPos));
col += vec3(1., .96, .9) * s * step(0., h);
float lines = step(.5, fract(-h * 90.)) * exp(-pow((uv.x - .5) * 7., 2.)) * step(h, 0.);
col += vec3(.6, .45, .35) * lines * .35 * uDawn;        // 水里的倒影
```

## 技巧卡

- 【心跳数跟着剧情走】文案讲等待和情绪时用 → 全屏一条心电线加右上 BPM，消息到达时 R 波翻倍，BPM 跳 → 每拍幅度写进数组，事件改写当前拍 → 改 3:4 时线放屏高 30%，聊天框放下面，上下分开，少一次遮挡
- 【时钟快进】文案说等了很久时用 → 对话框里一个大钟 8 秒走 4 小时，分钟越跳越大 → 用非线性时间表直接写几个关键值 → 改 3:4 时钟放聊天框上方，字高可以到屏高 8%
- 【后面的数字别停】大字盖住图表时用 → 图压到 20%，计数在字后面继续跳 → 计数层不受压暗影响，只降透明度 → 改 3:4 时计数放字下方，别被字挡住
- 【拉杆接下拉】要把两个比喻接起来时用 → 老虎机拉杆往下，叠化成手指下拉刷新 → 两个动作同方向、同时长，叠化放在动作中间 → 改 3:4 时手机本来就是竖的，比横屏更合适
- 【预测准了，尖峰就平】文案说习惯了没感觉时用 → 同样的消息，起伏一次比一次小，最后是直线 → 幅度乘 exp(−n/τ)，n 是出现次数 → 改 3:4 时两条线上下排，各占屏高 30%
- 【线不动，世界长出来】要把图表翻成风景时用 → 软闪一下，线变地平线，天和水在它周围出现 → 线那层不切换，只在背景层做 uDawn → 改 3:4 时地平线放屏高 45%，天更高，太阳更大
