# 文案到画面

排场面表时用。先看这句字幕属于哪种情况，再挑技巧。括号里是片名，细节在 `技巧卡全集.md` 和 `反推/`。

同一张卡一条片子只用一次。挑的时候想：这个动作和字幕说的是不是同一件事。

## 开场（0–17 秒）

| 文案情况 | 技巧 |
|---|---|
| 要把观众变成当事人 | 掉进瞳孔（光遗传学）、入水再出水（不会起风） |
| 结论本身就是悬念 | 竖光切开答案（37 法则） |
| 连续打脸 | 四句四小节（以牙还牙） |
| 此刻正在发生 | 数字替你读秒（中微子）、读数归零（我爱你） |
| 一个悖论 | 分屏一句一半（学鸟） |
| 有一个很小的具体物件 | 一滴泪砸出片名（银牌） |
| 不动的东西很奇怪 | 两块表一动一不动（拼尽全力） |
| 暴力开场 | 三拳打裂屏幕（脑内擂台） |

## 数字

| 文案情况 | 技巧 |
|---|---|
| 量化一个抽象的东西 | 给一句话装读数（我爱你） |
| 多到没概念 | 数字写到爆屏再换指数（时间倒流）、把数真算出来打满一行（熵增） |

| 大数据 | 每格都是真数据（以牙还牙） |
| 概率 | 一百次人生摊成格子（37 法则） |

| 一串百分比 | 数字真的在跑（镜像分子） |
| 努力了没变化 | 两块表（拼尽全力）、只认全对的记分牌（涌现） |
| 每次翻倍只换来一点 | 台阶代替曲线（涌现） |
| 揭穿一条很准的线 | 纵轴一压露馅（剃刀） |
| 差距一样，意义相反 | 一把尺子量两头（银牌） |
| 距离 | 两条线一个距离表（不会起风） |
| 数字本身很小 | 秒表按真实时间走（学鸟） |
| 大字盖住图 | 后面的数字别停（上头） |
| 全片讲同一规律、案例很多 | 角上的分数永远在涨（刷分） |
| “再也没有”要量化 | 时钟狂奔当笑点（刷分） |
