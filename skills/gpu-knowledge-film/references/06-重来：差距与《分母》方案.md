# 推倒重来：差距量化与新片《分母》方案 · 2026-10-31

## 一、这次才看清的差距

同一把尺子量他 21 条（中位数）和我们《聚光灯》v4：

| 指标 | 他的中位数 | 聚光灯 v4 | 差几倍 |
|---|---|---|---|
| 每分钟切换次数 | 11.9 | 2.96 | 4.0 |
| 平均帧差（运动量） | 1.02 | 0.38 | 2.7 |
| 运动像素占比 | 7.2% | 2.7% | 2.6 |
| 全片明暗起伏 | 5.2 | 2.1 | 2.5 |
| 非黑面积 | 15.8% | 9.1% | 1.7 |
| 色彩量 | 5.4 | 2.5 | 2.2 |

看大图后的结论（之前的总结错在把他理解成「黑底发光线描」）：

1. **他是真着色渲染，不是线描。** 虹膜有纤维、指纹有脊线、水面有泡沫、乐高有软阴影、金球有高光、地球有云和城市灯光。用的是 Opus 写的代码（简介自述），所以做得到。
2. **约每 8 秒换一个全新世界。** 《刷分》一条片里有：俯瞰河道、3D 乐高、发光迷宫、木地板扫地机、河内地图、代码终端、月球、暖光厨房。我们一条片只有「灯 + 火柴人」一个母题。
3. **主体占满画面。** 物体占屏 50% 以上，还会 0.5 秒内推到 3 倍。我们的东西都是黑底上一小块。
4. **事件有脉冲。** 闪白 → 从辉光里浮出大字；0.5 秒快推；神经元「炸开」整屏曝光冲顶；径向拉伸穿越。不是匀速慢动。
5. **同一种东西要成千上万个。** 分叉树几百条、斑马线几万粒、流线上万根、364 天的格子。密度本身就是冲击力。
6. **片名放在音乐第一次爆发上。** 《回去》的片名在 40 秒，不是固定 17 秒。

## 二、新管线（旧引擎整体废弃）

| 环节 | 旧 | 新 |
|---|---|---|
| 渲染 | Canvas 2D，CPU | three.js + 自写 GLSL，Chrome 走 M1 Max Metal GPU |
| 色彩 | 8 位 | 半浮点 HDR → 8 级 Bloom → ACES 色调映射 |
| 质感 | 线条 + 辉光 | PBR 材质、程序纹理、视差内部贴图、体积光 |
| 运动模糊 | 无 | 每帧多次子采样累积，真运动模糊 + 真景深 |
| 出帧 | 截屏 | readPixels 原始帧直通 ffmpeg |
| 速度 | 约 1–2 fps（多进程） | 单进程 GPU，约 5–10 fps |

## 三、新选题《分母》

**一句话**：连续说中十次的老师，只是把十万人筛了十轮。你看到的所有奇迹都只是分子，而你，是别人奇迹的分母。

**世界**：一面 250 列 × 400 行、正好十万扇窗的巨墙。每扇窗是一个人，真抽样、真淘汰。墙的宽高比正好 3:4。
**贯穿物**：分数线（标题、水面、玻璃地板都是它）。
**配乐**：曲 8《回去》（Move Up），157.5 秒，E 大调，无鼓，120 BPM。40.46 秒、120.46 秒两次爆发，95–119 秒沉到谷底，结构天然就是「设局 → 揭穿 → 沉下来 → 反转」。

## 七、审片后改了什么

没参与制作的审片人第一轮的结论是「单帧质感到位，但下限差，字压主体十余处」。据此改动：字幕区统一压黑且不随换句闪烁；说明字放大到 64 px 左右；数字、人名全部放进黑区；飞机缩小后露出完整梯形翼，加整流罩和桨盘；金沙拆成四个机位切在拍点上；后五轮改成一道分数线从上往下扫；真实案件数字停够 3 秒；「是你筛掉了他」改成老师头像滚出筛盘；片尾出处压黑底。

第二轮复审后又改：其余人家亮小灯，一眼看出是窗；分数线下的暗窗提亮；老师头像放大并滑行，不再打转；片尾加长 1.5 秒让出处停够 3 秒；基金金山去掉中缝；所有计数上方压实。

第三轮复审后局部重渲四段：片名开头和片尾让墙铺满画面，不露硬边；点燃时压低背景；金币段桌面压黑；远景窗格降低对比，减少压缩后的闪烁。
